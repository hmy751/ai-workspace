# 현재 세션 대화 전체를 확인한다

[improvement-loop](../SKILL.md)가 이번 세션의 시작부터 요청까지 훑을 때 사용한다. 원문 위치와 발화를 확인하는 공통 방법은 [대화 원문 접근](../../shared/conversation-source.md)을 따른다.

1. 현재 세션과 요청까지의 끝 지점을 식별한다. 앞부분이 압축·이관됐다면 같은 세션의 원문과 필요한 이전 연결을 확인한다.
2. 사용자·AI 발화를 시작부터 요청까지 순서대로 훑는다. 길면 연속 구간으로 나누고 남은 범위를 이어간다. 모든 발화를 같은 깊이로 분석하지는 않지만 검색 결과나 마지막 작업만으로 전체 검토를 대신하지 않는다.
3. 맥락에 유효하게 읽은 구간은 재사용하고, 중요한 주장에 필요한 도구 결과·실물은 해당 장면에서 확인한다. 후보 설명에 필요한 최소 발췌·출처·한계를 남기며 영구 열람 장부를 만들지 않는다.

원문을 확보하지 못하면 어느 구간이 요약뿐이고 어떤 결론에 영향을 주는지 밝힌다. 가능한 복구를 먼저 수행하며 중요한 공백만 사용자에게 확인한다. 부분 근거로 독립 판단 가능한 개선은 계속하되 전체 대화 검토는 미완료로 남긴다. 기록 스킬이 이전에 읽거나 반영한 범위가 이 루프의 전체 검토 범위를 줄이지 않는다.
