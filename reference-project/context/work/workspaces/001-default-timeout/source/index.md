# Source inventory

이 파일은 `001-default-timeout` Workspace가 작업 입력으로 선택·보존한 원자료 snapshot과 provenance의 inventory다. 원자료의 저자와 정본 권위는 원래 출처에 남고, 이 Workspace는 사용한 범위와 시점을 다시 확인할 수 있게 관리한다.

현재 이 Workspace가 별도 보존한 원문이나 snapshot은 없다. Timeout의 제품 기준은 Project canonical인 [`context/project/`](../../../../project/)에 있으며 이 source에는 복제하지 않았다.
