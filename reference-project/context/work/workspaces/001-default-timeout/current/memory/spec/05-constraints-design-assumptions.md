# 제약·현재 설계·가정

## 제약

- Python 표준 라이브러리만 사용한다.
- 기본 timeout의 canonical 결정은 Workspace가 아닌 Project의 [결정 문서](../../../../../../project/decisions/0001-default-timeout.md)가 소유한다.
- 유효하지 않은 설정을 임의 보정하지 않는다.

## 현재 설계와 이유

[config loader](../../../../../../../src/config_loader.py)가 입력 검증과 기본값 적용을 맡고, frozen dataclass `RequestPolicy`를 반환한다. 호출자가 검증된 값을 이후 바꾸지 못하도록 하는 현재 구현이다. 구체적인 내부 방식이 앞으로도 최선인지는 관련 변경 때 다시 판단할 수 있다.

## 가정과 확인 범위

입력 dict를 만드는 파일 파싱·환경 변수 병합과 policy를 사용하는 네트워크 실행은 이번 범위 밖이다. 이 경계가 달라지면 입력·출력 계약과 검증 범위를 다시 살핀다. 테스트나 기록의 존재만으로 외부 실행까지 검증됐다고 가정하지 않는다.
