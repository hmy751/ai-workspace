# Project context 작성·읽기 기준

이 디렉터리는 `context/project/` 본문을 어떻게 구성하고 관련 작업에서 어떻게 선택·적용할지에 대한 관리 기준을 소유한다.

- [내용 선별과 주제 구성](composition.md): 무엇을 남기고 어떤 질문·문서·층으로 구성할지 판단할 때 읽는다.
- [읽기와 적용](reading.md): 관련 작업에 필요한 본문을 고르고 계약·예외·현재 차이를 적용할 때 읽는다.

이 디렉터리는 `common/current/guidance`와 나란한 제품 내용 층이 아니다. 제품·domain 의미와 작업 계약은 각 본문이, 변경 권한·갱신 시점·완료 확인은 [관리 계약](../MAINTENANCE.md)이 소유한다. 구성·읽기 기준은 필요한 작업에서 직접 읽고 일반 Recover의 기본 입력으로 추가하지 않는다.
