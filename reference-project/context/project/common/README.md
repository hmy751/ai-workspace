# Common Project context

이 폴더는 여러 Work에 지속되는 제품·사용자·domain 의미와 Project-wide 제약을 소유한다. 구현 현황이나 한 Workspace의 목표가 아니라, 작업이 달라져도 같은 판단 기준으로 남는 내용을 둔다.

## 현재 문서

- [`prd.md`](prd.md): Request policy config의 사용자 장면, 목적, 완료 기준과 범위의 normative Owner

새 문서는 독립된 공통 의미가 있고 별도 수명과 Owner가 필요할 때만 추가한다. 기존 제품 문서가 상세 canonical이면 그 위치와 충돌 우선순위를 밝히되 링크만으로 필요한 의미를 대신하지 않는다. 제품 의미나 Project-wide 제약이 바뀌면 그 결정을 내린 주체가 관련 문서를 함께 갱신한다.
