# Current Project context

이 폴더는 현재 구현·지원·미지원 범위, 연결 구조와 proof boundary를 사람이 찾기 위한 교체형 Project-level 지도를 소유한다. 실제 코드·테스트·실행 설정이 상세 Owner이며, 이 층은 그 사실을 복제하지 않고 현재 판단에 필요한 경계와 접근점을 연결한다.

## 현재 문서

- [`architecture.md`](architecture.md): Request policy config의 현재 구성요소, 실행 경로, 지원 범위와 검증 상한

각 문서는 마지막 대조 시점과 대상, 상세 Owner, stale 신호와 갱신 책임을 밝힌다. 상세 Owner가 바뀌거나 현재 지도와 충돌하면 그 변경을 수행한 주체가 claim 범위를 다시 대조해 이 층을 갱신한다.
