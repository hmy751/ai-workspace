# Current Project context

이 폴더는 현재 구현·지원·미지원 범위, 연결 관계와 proof boundary를 사람이 판단하기 위한 교체형 Project-level 맥락을 소유한다. 완료된 구조와 지원 범위도 다루며 미정·위험 목록에 한정하지 않는다. 실제 코드·테스트·실행 설정이 상세 Owner다.

## 현재 문서

- [`architecture.md`](architecture.md): Request policy config의 현재 구성요소, 실행 경로, 지원 범위와 검증 상한

별도 본문은 관련 가이드와 코드를 읽은 뒤에도 어떤 판단을 더 가능하게 하는지, 어떤 변화에서 다시 확인할지 설명할 수 있어야 한다. 한 함수 흐름이나 한 번의 검사 결과를 현황으로 복제하는 데 그치면 기존 본문이나 Work 기록으로 연결한다. 대조 시점·대상, 상세 Owner와 갱신 책임은 실제 판단에 필요한 범위에서 밝힌다.
