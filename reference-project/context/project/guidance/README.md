# Project guidance

이 폴더는 관련 제품 작업에서 지킬 구체적인 개발 계약과 이유, 적용·변경 판단·검증 방법을 소유한다. 각 본문에서 적용할 작업과 중요한 예외를 이해할 수 있어야 한다. 모든 가이드에 같은 항목이나 서식을 강제하지 않는다.

현재 Request policy 제품에는 이 층에 따로 나눌 제품 가이드를 두지 않았다. 제품 입력 계약은 [제품 요구](../common/prd.md), 지원 범위는 [현재 구조](../current/architecture.md)에서 읽는다. 빈 가이드나 다른 제품의 사례를 현재 제품 계약처럼 채우지 않는다.

공통 설명 방법은 [스킬 공통 기준](../../../.agents/skills/shared/explanation-and-evidence-criteria.md)으로 옮겼다. `work-discussion`과 `explain`이 각 호출 조건에서 사용하며 이 제품의 고유 계약이나 모든 Recover의 필수 입력은 아니다. 소비자와 호출 관계는 [스킬 색인](../../../.agents/skills/README.md)이 연결한다.

새 guidance는 관련 작업에서 지속해서 적용할 계약·판단·검증이 있고 기존 본문으로 충분히 설명되지 않을 때 추가한다. 적용 조건이 사라지거나 다른 canonical이 그 책임을 직접 소유하면 통합·제거한다. 구성과 갱신은 [Project 구성 기준](../REFERENCE/composition.md)과 [관리 계약](../MAINTENANCE.md)을 따른다.
