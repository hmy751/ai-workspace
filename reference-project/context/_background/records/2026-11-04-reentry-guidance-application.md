# Reference의 재개 안내 전환

2026-11-04. Prototype의 재개 안내·직접 검사 흐름을 Reference에 반영하며 context·Project 진입의 `recover.json`과 공용 Harness 의존 설명을 맞췄다. Project 본문의 의미·권위·내용 구성은 유지하고 Work의 Project 선택 문서가 목록·이유를, `recover.md`가 그 선택을 읽을 조건을 맡는다.

사용자는 세션이 달라도 흐름과 뉘앙스가 유지되면서 전체 Workspace를 매번 읽지 않는 기준을 요청했다. 별도 recover류 파일은 유지하되 JSON으로 고정하지 않는 선택에 따라 Work 지침·Markdown 안내·기존 current를 연결했다. 적용된 현재 역할은 [context](../../README.md), 변화와 기존 실행 증거의 보존 위치는 [Work 전환 기록](../../work/workspaces/001-default-timeout/records/2026-11-04-recovery-guide-transition.md)에서 찾는다.

이 연결 변경은 제품 계약 변경·Work 완료·실제 운영 설치나 장기 효과 확인을 뜻하지 않는다. 이전 prototype의 형성 기록과 당시 유보는 역사로 보존한다.
