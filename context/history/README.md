# History

이 폴더에는 작업 중 생긴 상세 기록, 판단 변화, 시도, 실패, 검증 결과를 날짜순으로 쌓는다. history는 “무슨 일이 있었고 왜 바뀌었는가”를 복구하는 곳이지, 지금 유효한 상태의 owner가 아니다.

## 기록 규칙

- 파일명은 `YYYY-MM-DD-NN-주제.md` 형식을 사용한다.
- 하나의 의미 있는 작업이나 판단 전환을 한 문서로 남긴다.
- 확인한 사실, 당시 판단, 검증 결과, 남은 불확실성을 구분한다.
- 완료된 기록의 의미를 나중 상태에 맞춰 다시 쓰지 않는다. 정정이나 후속 판단은 새 history로 남긴다.
- 비공개 대화 원문이나 대용량 원자료를 복제하지 않고 `source/`의 canonical 자료를 가리킨다.

## active로 반영하는 기준

history에 기록됐다는 이유만으로 active가 되지 않는다. 다음 작업에도 필요한 현재 사실·결정·제약이고 적절한 근거로 확인된 경우에만 [`../active/`](../active/)의 해당 owner 문서를 갱신한다.

재진입 시에는 history 전체를 읽지 않는다. [`../active/index.md`](../active/index.md)에서 필요한 기록만 선택해 들어온다.
