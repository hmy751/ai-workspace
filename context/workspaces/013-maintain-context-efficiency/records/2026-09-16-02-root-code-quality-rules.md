# 코드 작업 기준의 루트 연결

사용자는 이번 대화에서 합의한 코드 규칙을 다른 코드 작업에도 적용하도록 저장소 최상단에 추가하고 `AGENTS.md`와 `CLAUDE.md`에서 연결하도록 요청했다.

루트 [`CODE-QUALITY.md`](../../../../CODE-QUALITY.md)에 책임별 응집도와 파일 배치, 실제 도구 차이의 분리, 리팩터링 동작 보존, 읽고 검토할 수 있는 테스트, 한국어 설명 주석, 코드·테스트 진입점과 검증 범위를 정의했다. Maintain의 특정 디렉터리 이름이나 Recover·Verify를 미룬 작업 순서는 다른 코드의 고정 규칙으로 올리지 않았다.

루트 [`AGENTS.md`](../../../../AGENTS.md)의 Code work에서 코드 작업을 시작할 때 읽도록 연결했다. 루트 `CLAUDE.md`는 기존 `AGENTS.md` 상대 symlink이므로 별도 본문 복제 없이 같은 규칙을 사용한다. 이 기준은 이 저장소 범위이며 전역 사용자 지침이나 독립적으로 실행·이식되는 다른 저장소의 지침을 변경하지 않았다.

공통 문서의 로컬 링크에 누락이 없고, `CLAUDE.md → AGENTS.md` symlink 대상과 두 진입점의 본문이 동일함을 확인했다. `git diff --check`는 통과했다. 이 문서 변경을 위해 프로덕션 테스트를 다시 실행하지 않았다.
