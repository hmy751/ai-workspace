# Ticket

각 본문이 실행 범위·접근·완료 조건·현재 상태와 실제 결과를 소유한다. 전체 상황과 다음 행동은 [state](../../state/index.md), 조사 범위는 [후보 목록](../analysis-items.md)에서 찾는다.

- [01 — 경비 합계의 강조·소수 자릿수 규칙](01-expense-summary.md): 통화 합계의 판단과 표시 규칙을 읽기 쉽게 한다.
- [02 — 도시 검색의 선별 조건과 변환](02-city-search.md): 요청 도시 코드와 응답 필터·변환의 의미를 정리한다.
- [03 — 저장 용량의 집계·부분 실패·표시](03-storage-stats.md): 부분 결과를 보존하며 표시 조립의 중복을 줄인다.
- [04 — 경비 API의 요청·검증·반환 흐름](04-expense-api.md): 오류 책임을 유지하며 부수 코드가 가리는 흐름을 드러낸다.
- [05 — 서버 일정 응답의 날짜 변환](05-schedule-response.md): 동일한 DB row의 응답 날짜 변환을 한 의미로 관리한다.
