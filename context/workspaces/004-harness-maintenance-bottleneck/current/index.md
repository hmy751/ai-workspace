# Harness maintenance bottleneck current

마지막 갱신: `2026-08-14`

이 폴더는 context+harness 유지보수 병목 개선 작업의 현재 상태를 소유한다.

## 재진입 순서

1. [`memory.md`](memory.md)에서 목표와 유지할 기준을 확인한다.
2. [`state.md`](state.md)에서 현재 관찰, 불확실성, 다음 행동을 확인한다.
3. [`../output/index.md`](../output/index.md)에서 선택된 개선 산출물이 있는지 확인한다.
4. 상세 근거가 필요할 때만 [`../records/`](../records/)를 읽는다.

다른 Workspace의 current·records 전체를 기본 입력으로 읽지 않는다. 현재 병목을 설명하는 데 필요한 접근점만 이 Workspace가 선택한다.
