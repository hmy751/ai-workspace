# Reference implementation output

이 파일은 `001-reference-implementation` Workspace의 goal을 위해 선택된 현재 산출물과 실제 canonical 위치를 연결한다. 실제 산출물을 이 폴더에 복제하지 않는다.

## 현재 goal 산출물

- 산출물: [실행 가능한 Project–Workspace context+harness reference](../../../../output/README.md)
- 실제 위치: 저장소 루트 `output/`
- 범위: Project context, Work context, sample Workspace, recover·verify Harness, 제품 코드와 테스트가 함께 동작하는 reference
- Workspace 상태: reference 구현과 현재 책임 경계 변경은 완료 상태
- Runtime 상태: sample Workspace의 최신 고정 검증은 `verified_waiting_acceptance`이며 사람의 acceptance나 운영 효과를 뜻하지 않음

이 index는 루트 `output/`이 이 Workspace goal의 산출물이라는 선택 관계만 관리한다. 실제 파일과 구성 설명의 canonical은 루트 [`output/`](../../../../output/)에 있고, 분석 과정·후보·결정 근거·검증 과정은 [`../records/`](../records/)에 남는다.
