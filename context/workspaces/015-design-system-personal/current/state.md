# 현재 상태

마지막 갱신: `2026-11-06`

## 현재 단계

자료 수집, 독립 개선 검토, 프로젝트 간 계승과 책임 조사, Personal 없는 기준선 측정을 마쳤다. 독자, template 활용, 경험이 적은 주제의 표시, 반영 위치(`reference-project` 우선)를 사용자가 정했다. 사용자가 1차 초안의 범위가 좁다고 보아 [`초안 범위 재검토`](../records/collection/14-draft-coverage-review.md)의 구성안을 택했다. 이에 따라 한 주제 안에서 영역별 본문으로 나눈 2차 초안과 형성 자료(`_background`)를 Git 밖에 썼다. 근거 표의 전수 검토 전에 [재측정부터 하기로](../records/2026-11-06-01-draft-structure-and-remeasure.md) 했다. 채택하지 않았으므로 `reference-project`에는 반영하지 않았다.

초안은 [`Personal 초안`](../records/collection/personal-draft/design-system/INDEX.md), 현재 판단은 [`현재 판단`](../records/collection/08-review-adoption.md), 측정 결과는 [`기준선 관찰`](../records/collection/13-baseline-observations.md)에 있다. 모두 Git에서 제외되어 있다.

이 Workspace는 [Workspace 목록](../../README.md)에 active가 아닌 준비 상태로 올렸다.

## 열린 결정

- **active 전환**
- **재측정 모델:** 기준선 세션의 모델과 추론 수준을 사용자에게 확인한다. 확인할 수 없으면 비교의 한계로 남긴다.

## 검증의 한계

- 기준선 화면은 웹 미리보기로 일부만 확인했다. 사용자가 네이티브 확인은 하지 않기로 했다.
- 사람과 AI의 작성 비율, 프로젝트 간 복사 경로는 확인하지 못했다.
- 추가 조사 결과는 Main이 표본만 원본과 대조했다.
- 초안의 실제 효과는 아직 시험하지 않았다. 기준선 세션의 모델과 추론 수준 기록이 없어 재측정 전에 확인이 필요하다.
- 형성 자료는 공개 가능한 근거로 구성했고 비공개 근거는 그 존재와 확인 한계만 적었다. 본문 규칙 다수는 작성자의 일반화이며 사용자가 한 문장씩 승인한 것은 아니다.

## 다음 행동

1. 기준 커밋에서 새 사본을 만들고 초안과 입구 한 줄만 더해 같은 지시문으로 재수행한다. 맞는 본문을 읽었는지도 함께 본다.
2. 사용자가 전후를 비교하고, 결과에 관련된 규칙부터 고칠 점과 채택 여부를 정한다.
3. 맥락 없는 세션의 도달을 확인한다.
4. 채택한 본문과 형성 자료를 `reference-project`의 Personal에 먼저 적용하고 개발 판단 안내에 입구를 더한다.
