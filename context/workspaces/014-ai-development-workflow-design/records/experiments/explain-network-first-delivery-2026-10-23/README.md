## 입력과 실행 경계

source06의9~844 공개 발화34개와895 첫 보고 직전 자료를 제공했다. 코드 작업 전·후, diff, 관련 코드, 당시 문서·검사·검토는 두 조건에서 해시가 같다. 원자료는 보존 사본이며 실제 제품 실행 환경을 재현하지 않았다. 이후 첫 보고·사용자 정정·철회, 현재 평가·설계 기록·형성 배경은 입력에서 제외했다.

각 실행은 지정 스킬 본문과 대화 원문을 먼저 완독하고, 이후에는 필요한 파일을 선택한다. 선택한 파일은120행 조각으로 전문을 읽고 reader가 읽은 구간·시각·해시를 기록한다. 모든 파일을 읽도록 요구하거나 기대 답·목차·분량·코드 삽입을 별도로 지시하지 않았다. 코드 수정·검사 재실행·추가 agent·커밋은 금지했다. 응답과 짧은 실행 기록만 작성한다.

별도 실행 사본과 reader의 허용 경로 검사를 사용했다. 에이전트 전체 도구를 OS 수준에서 격리한 것은 아니며, 읽기 기록과 실행자 보고를 대조한다. 현재 사용자 대화는 상속하지 않았다. 두 실행에 동일한 상위 실행 환경은 남으므로 원래 역사적 세션을 그대로 재현했다고 주장하지 않는다.

## 평가 질문과 후속 판단

변경의 성격·의미가 실제 자료와 연결되는지, 합의와 결과를 근거로 대조하는지, 첫 답으로 다음 판단을 할 수 있는지, 정확성과 읽기 부담을 함께 본다. 후속 사용자의 철회 결론을 정답으로 정하지 않는다. 과거 검토자의 합의 충족 판정도 검증된 정답으로 취하지 않는다.

이 시험은 명시 적용한 설명 방법의 비교다. 자연 선택·구현 중 범위 확대 예방·실제 운영의 일관성을 검증하지 않는다. 양쪽이 비슷하면 우세 미확인으로 남긴다. 핵심 미수행이 남으면 해당 근거로 원인을 좁히며 같은 사례에서 좋은 답이 나올 때까지 재생성하지 않는다.

사용자에게는 조건명이 없는 두 최초 응답 전문을 제시한다. 문장·링크·형식을 고치지 않으며 평가 해설이나 승자 판단을 앞에 붙이지 않는다. 사용자 이해 효과는 응답 생성·정적 검사만으로 확정하지 않는다.

## 실행 결과

두 최초 응답을 각각 한 번 생성·보존했다. 입력 변경과 reader 조각 해시 불일치는 없었다. 두 실행 모두 지정 스킬을 먼저 읽었다. 그러나 두 실행 모두 일부 도구 출력 잘림을 보고했고 한 실행에서는 선택한 코드 파일3개의 후반70행을 읽지 않았다. reader가 내용을 출력했다는 로그는 화면에서 잘림 없이 읽었다는 증거가 아니므로, 다른 실행의 구간 누락0도 완독 성공으로 올리지 않는다. **합의한 읽기 조건 미충족으로 이번 비교의 조건 충족을 인정하지 않으며 스킬 우열 판단을 보류한다.**
