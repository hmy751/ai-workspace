# 현재 시스템 조사

2-A·2-B와 공통 조회 훅 적용은 끝났고, 다음 계획에는 2-C 복구 알림이 남아 있다.
접근 제한이 풀리면 같은 계정·여행의 기존 데이터를 바로 보여 준다. 새 조회가 필요한지는 Query가 판단한다.
상단 헤더는 online·offline·unknown을 표시한다.
Network Store는 같은 상태의 반복 관측을 걸러내고 재확인 요청을 합쳐 처리한다.
Policy와 조회 조합은 내용 표시 허용·조회 실행 허용을 판단한다.
Query는 캐시·로딩·갱신·조회 오류를 관리한다. Sync는 조건이 갖춰지면 동기화와 변경 후 갱신을 맡는다.
공용 토스트 구현은 확인되지 않았다.
사용자가 복귀를 얼마나 잘 알아차리는지에 대한 UX 관찰은 아직 없다.
