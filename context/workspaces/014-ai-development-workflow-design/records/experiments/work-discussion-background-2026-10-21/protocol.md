# 형성 자료 이해·수정 판단과 실행 소비 경로 확인

2026-10-21. 사용자 요청으로 서로 이력이 없는 두 실행에 gpt-6.1-sol·medium을 배치한다. 각1회만 실행하며 추가 평가자는 두지 않는다. 형성 자료 실행에는 형성 자료만, 실행 소비에는 실제 스킬·공통 기준·정책과 형성 자료를 모두 접근 가능하게 둔다. 소비 실행에는 별도의 background 읽기 금지나 기대 답을 주지 않는다. 사후 정정·재시도 없이 Main이 원응답과 읽기 기록을 판정한다.

형성 자료 실행은 구성 이유·선택·관찰 한계를 복원하고 간결화 요청의 수정 판단을 내릴 수 있는지 확인한다. 실행 소비는 기존 표시 보존에서 통일로 바뀐 D2 모의 요청을 재사용한다. 제품 코드는 없고 제한된 관찰을 제공한다. 필요한 선택을 판단했는지와 읽은 자료의 역할을 함께 본다.

모든 입력 본문은 동일한 read.py 도구로 읽고 읽은 경로를 기록하도록 요청한다. 파일 목록 조회와 본문 읽기는 구별한다. 이는 지시 기반 기록이며 OS 접근 격리·전체 도구 이력 감사는 아니다. 경로가 보여도 읽기를 금지하지 않는다. 입력 사본·해시·프롬프트·원응답·읽기 기록을 보존한다. 본문 수정·실제 설치·장기 신뢰성은 이 확인 범위가 아니다.
