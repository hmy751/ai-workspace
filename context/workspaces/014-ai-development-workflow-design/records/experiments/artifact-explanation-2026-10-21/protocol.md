# 설명 스킬 판본 비교 계획 — 응답 생성 전 고정

세 실제 대화 장면에 동일 입력과 동일 공통 기준을 주고 기존판·수정안 각각 한 번 응답한다. 장면은 일정 작성 후속 브리핑, Promise 후속 설명, access 위치 질문이다. 각 실행은 대화 이력을 상속하지 않는 새 에이전트이며 같은 기본 모델·추론 설정을 사용한다. 한 실행자는 한 스킬 판본만 읽는다. 기대 답안·개선 의도·후속 사용자 정정·원래 후속 AI 답·이번 설계 기록을 제공하지 않는다. 판본별 경로는 run ID로 가리고 공통 기준 링크만 동등하게 정규화한다.

원문 구간은 manifest에 고정했다. 시간상 마지막 사용자 발화 뒤의 대화는 제외한다. 입력은 과거 대화 보고와 그 안의 코드 발췌로 제한한다. 따라서 원래 환경의 코드 조사·검증 수행을 재현하는 실험은 아니며, 같은 자료에서 만드는 후속 설명·판단의 차이를 비교한다. main은 장면을 선택했으므로 사례 선택의 편향 가능성이 있다.

응답은 최초 결과를 수정 없이 고정하고 해시를 남긴다. 평가자는 원문과 두 익명 응답만 읽으며 판본·스킬·변경 목표를 받지 않는다. 질문 충족·사실 근거·가독성·불필요한 확대를 판단하되 기준과 중요도는 직접 정하고 동률·판단 불가를 허용한다. 두 평가자에게 표시 순서를 반대로 제공한다. 최종적으로 main이 원문·응답·평가를 대조하고 버전을 공개한다. 반복 측정·장기 사용자 이해 효과·스킬 변경의 단독 인과는 주장하지 않는다.
