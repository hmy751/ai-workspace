# 두 설명 스킬의 같은 장면 응답 비교

[결론과 실제 문장 대조](../../2026-10-21-ticket04-02-blind-response-comparison.md)를 먼저 읽는다. 세 원문 장면에 기존판·수정안 각 한 번씩 응답하고 두 평가자에게 순서를 반대로 표시한 익명 비교다. 응답 품질의 일관된 개선은 확인하지 못했다.

- [생성 전 계획](protocol.md): 입력 경계·독립 생성·평가·한계.
- [판본과 해시](manifest.json): scene·run·원본 스킬·원문 구간·입력과 응답 해시.
- inputs/: 마지막 질문 시점까지의 원문 세 구간.
- runs/: 여섯 실행의 prompt·스킬 사본·공통 기준·최초 응답·receipt.
- reviews/: 평가자별 익명 입력·지시·최초 평가.
- [표시 매핑](review-mapping.json): 판본을 공개해 평가를 재해석하는 대응표.

원응답·판본·입력·평가를 결과에 맞게 고치지 않는다. 이 폴더는 실험 증거이며 현재 적용할 스킬 정본이나 제품 검증 결과가 아니다.
