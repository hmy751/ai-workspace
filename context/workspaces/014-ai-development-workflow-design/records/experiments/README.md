# REA 조사 실험 자료

**참고 자료로 보존한 실험 묶음이다.** 2026-10-16 사용자는 REA를 이번 작업에서 보조 도구 정도로 보고, 정식 도입이나 설계·운영 기준에 바로 반영하지 않고 조사를 마무리하도록 요청했다. 최종 판단과 사용자 원문은 [마무리 기록 46](../2026-10-16-46-rea-reference-research-close.md)에 있다.

고정 초안과 원자료·기계 증거는 당시 상태와 hash를 유지한다. 지금의 보존 지위는 이 안내와 마무리 기록에서 확인한다. 실행 스크립트가 있다는 이유로 자동 실행하거나 도구 설치·MCP 등록을 수행하지 않는다. 재현이 필요한 경우 각 protocol에 적힌 범위와 임시 의존성 설치 방법을 따른다.

보고서·컨텍스트 예시를 현재 `output`이나 Ticket 진행으로 자동 승격하지 않는다. 다시 활용할 실제 질문이 생기면 당시 버전·입력·검증 상한과 현재 코드를 먼저 대조한다.
