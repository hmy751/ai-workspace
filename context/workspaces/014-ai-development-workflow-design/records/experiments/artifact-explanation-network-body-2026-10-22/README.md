## 자료 경계와 결과 보존

사용한 원자료는 source/artifact-explanation-scenes/03-network-flow에 보존되어 있다. 원문 범위·도구 관측과 파일 추출은 그곳의 manifest와historical-materials/manifest.json에서 재확인한다. 실행자에게는 필요한 파일만 별도 임시 폴더로 복사했다. 상위Workspace·원 저장소·다른 결과 접근을 제한했지만 이는 지시상 범위이며 시스템 수준 파일 접근 격리는 아니다. 읽기 기록은 실행자의 자기보고다.

각 실행자의 response.md와read-log.md를 변경하지 않고 output에 보존한다. Main은 원 코드·소비자·보존 테스트 및 이후 실제 대화와 대조하되, 이후 대화는 생성자에게 전달하지 않는다. comparison.md는 Main의 관찰과 판단이며 독립 평가자 판정이 아니다.

각 판본1회이므로 차이를 안정된 스킬 효과로 확정하지 않는다. 사용자 이해·재질문 감소, 자연 선택·조기 발동 효과는 별도 문제다. 이 질문은 이미 흐름 설명을 요청하므로 도식 존재 자체를 수정판 성과로 세지 않는다. 결과가 비슷하더라도 유리한 결과가 나올 때까지 재생성하지 않는다. 이번 추가 실행은network 한 장면이며 저장 용량·보고서 시험과 운영 스킬 변경은 포함하지 않는다.
