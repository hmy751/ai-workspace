첫 보고와 종합 UX의 시작 지침은 development이고 explain의 사용은 그 연결에 맡겼다. access·인증의 시작 지침은 explain이다. 현재 스킬의 필요한 상세는 선택하게 했고 형성 자료는 공급하지 않았다. 과거 원문에 등장한 옛 지침·명령·절대 경로는 역사 자료로 유지하며 현재 실행 지시나 추가 접근 권한으로 삼지 않았다.

access의 정확한 조합hook과 마지막 범위축소는 원본 도구 기록에서 재구성했다. 일정화면은 전체가 아닌 당시diff이고 폼은 발췌다. 각 `preparation.json`에 출처·변환·해시·한계를 보존했다. 그 준비 파일과 스크립트는 생성자 입력에서 제외했다.

종합 UX는 수집된 관찰을 넘겨받고 조사하는 제한 수행이다.619이후 관찰도 제공하므로619부터의 역사 실행 전체 재연이 아니다. 저장소의 과거 도구설정·스킬 폴더121파일은 제외했고 제품·검사·문서816파일을 보존했다. 실행 환경은 복원되지 않았으며 가능한 파일 조사·로컬 확인과 실제 기기 검증을 구별한다. Main이 미리 발견한 선택창 검사 문제나 특정 파일명은 생성자에게 알려 주지 않았다.

## 읽기·출력 보존

각 case의 `prompt.txt`, `required.json`, `inventory.json`, `images.json`은 실행 입력과 범위를 고정한다. `read_material.py`는3000자 조각의 열람·검색을 기록하며 필수 대화와 시작 지침은 완독을 확인한다. 다른 자료의 필요한 부분 선택은 허용하고 선택 파일의 부분 읽기도 기록한다. 읽기 로그는 이해·적용의 증명이나 모든 도구 접근의 완전한 감사가 아니다. 폴더·지침으로 범위를 구분했으며 OS 수준 접근 격리는 아니다.

각 `output/response.md`는 최초 응답을 한 번 작성한 원본이다. 실행 메모와 읽기·입력불변 검사 결과는 같은 output에 별도로 둔다. 사용자에게 제공하는 모음에는 사례 제목·구분선만 더하고 원응답을 편집하지 않는다. 작성 전 읽기 확인, 입력·조각·응답 해시는 Main이 대조한다. 잘림·범위 밖 접근은 실제 기록과 실행자의 보고를 구별한다.

이 수행은 네 장면의 현재판 책임을 확인하는 것이다. 모델이나 스킬의 일반 우세, 사용자의 실제 이해, 제품 운영 수락,04-02전체 완료를 입증하지 않는다. 답이 비슷하거나 마음에 들지 않는다는 이유로 재생성하지 않는다. 준비 단계의 파일명 가정 오류는 모델 호출 전에 수정했으며 응답 재실행에 해당하지 않는다.
