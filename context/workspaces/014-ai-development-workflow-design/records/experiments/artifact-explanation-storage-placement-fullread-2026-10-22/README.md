# 저장 용량 적용 배치 비교 — 조각별 완독 재실행

사용자는 이전 실행의 출력 잘림을 지적하고 자료와 적용할 스킬 전문을 빠짐없이 읽는 동일 조건 재시험을 요청했다. 원 대화·문서·수정 전후 코드·검사 결과·이미지·기존 스킬의 바이트는 유지했다. GPT-6-sol medium 새 컨텍스트 두 개에서 각1회 실행한다. A는 기존 조건의 선택권을 유지하고 B에만 결과 자료 전 명시 적용을 지시한다. 이후 교정·기대 답·이전 응답·평가는 제공하지 않는다.

텍스트를 최대4000문자로 나눠 호출당 한 조각만 출력하며 응답 예산은8000토큰 이상으로 지정한다. 파일별 모든 조각과 해시·읽기 시점, 이미지 열람·출력 잘림 여부를 확인한다. 실행 조건과 원 입력은 [conditions.json](conditions.json), 각 입력 폴더에 보존한다. [두 응답과 Main 대조](comparison.md), [전체 조각 대조·출력 해시](results.json)에 완료 결과를 보존했다. A 필수29조각, B 필수자료·스킬·공통 기준32조각을 누락 없이 확인했고 양쪽 모두 출력 잘림 없음을 보고했다.

이전 실행과는 자료를 완독하는 공통 절차가 달라졌으므로 이전 A/B와 이번 A/B 사이의 응답 차이를 스킬 효과로 해석하지 않는다. 이번 두 조건 사이에는 명시 적용 문장만 다르다. A에 스킬 본문을 강제로 읽히면 자연 선택과 명시 적용 비교가 바뀌므로, A가 스스로 선택한 경우 전문을 읽도록 했다. 기록된 파일 출력은 실제 이해 자체의 보장이 아니며 OS 수준 외부 접근 격리는 아니다.
