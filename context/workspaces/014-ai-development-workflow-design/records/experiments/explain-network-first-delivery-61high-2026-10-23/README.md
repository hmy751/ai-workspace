# 06 첫 완료 보고 — GPT-6.1-sol high 비교

사용자는6.0-sol medium 결과의 조건 공개·평가 뒤 “그럼 둘다 6.1 sol 하이로 시켜봐”라고 요청했다. 두 조건 모두 GPT-6.1-sol high의 새 컨텍스트에서 최초 응답을 각1회 생성한다. 직전 완독 재실행의 자료·스킬 판본·작성 prompt·reader를 바이트 그대로 복사했고 모델과 추론 수준만 변경했다. 스킬과 대화는 먼저 완독하고, 이후 필요한 파일은 선택해 읽는다. 선택한 파일의3000자 조각 전체를 응답 작성 전에 검사한다.

두 조건의 표시 순서는 실행 전에 무작위로 정했다. 실행자에게 이전 응답·평가·현재 대화·이후 원문은 제공하지 않는다. 조건 대응은 conditions.json에 보존하고 사용자에게는 조건명 없는 두 응답 원문을 제시한다. 자료는 별도 사본과 경로 검사 reader를 사용하지만 OS 수준 도구 접근 격리를 증명하지는 않는다.

같은 모델·effort 안의 두 응답을 비교한다. 이전 실행과의 차이는 모델과effort를 함께 바꾼 결과이므로 둘의 개별 효과로 분해하지 않는다. 자연 적용·구현 중 범위 예방·안정된 우세·실제 사용자 이해를 이 한 쌍으로 입증하지 않는다.

## 실행 완료

두 최초 응답을 생성했다. 선택한18개·31개 파일의 모든 조각을 응답 전에 읽은 기록이 있고, Main이 조각 해시·입력 불변·응답 전 검사 완료를 대조했다. 누락·해시 불일치·입력 변경0이며 두 실행자는 출력 잘림 없음으로 보고했다. 원문은 answer-A.md·answer-B.md에 동일 바이트로 보존하고 평가·조건명 없이 제시한다. 사용자 평가와 조건 공개 전이며 이번 실행만으로 우세를 확정하지 않는다. 응답 내용·링크·1인칭 표현은 수정하지 않았다. 실제 구현·검사 재실행은 없었다.

2026-10-24 사용자는 B가 더 낫다고 평가했고 조건 공개를 요청했다. 이번 A는 새 explain, B는 기존 브리핑이다. [Main의 목표별 평가와6.0 결과 종합](comparison.md)에 구현 대응의 기존판 우세 관찰과 해석 한계를 보존했다.
