# 인증 인터셉터 — GPT-6-luna medium 본문 비교

사용자는 앞선6.1-sol 비교에서 기존판도 교정 없이 자세히 설명한 결과를 확인하고, 같은 인증 사례를6.0 luna medium으로 다시 시험하도록 요청했다. 기존판·수정판을 각각 새 worker에서 한 번 실행한다.

## 입력과 적용 시점

- 모델 인수는 `gpt-6-luna`, 추론은 `medium`, 대화 상속은 `fork_turns=none`으로 지정했다.
- 앞선 인증 비교의 r31·r74 입력11개를 각각 그대로 복사했다. 실행 경로 외 새 설명 지시나 출력 형식은 추가하지 않았다. conditions.json에 출처·매핑·해시를 보존한다.
- 원문 사용자9의 문법 질문·AI13의 문법 설명·사용자20의 전체 코드와 동작 설명 질문이 입력이다. 이 마지막 질문에 대한 첫 답을 생성한다.
- 실제 AI48의 첫 답, 사용자55의 “코드랑 같이 자세히” 교정, 사용자73의 재질문과 보완 답은 제공하지 않았다. 현재 논의·앞선 실험 답·기대 답도 제공하지 않았다.
- 두 조건 모두 질문을 조사하기 시작할 때 지정 스킬을 읽고 적용하라고 명시했다. 따라서 “교정 없이”는 이후 사용자 교정이 없다는 뜻이며, 스킬의 자연 선택이나 무지침 응답을 시험하는 것은 아니다.
- 같은 당시 코드·사용처·프로젝트 안내·공통 기준에서 skill/SKILL.md만 다르다. 스킬은 기존10월 고정 판본이며9월 당시 전체 하네스 재현은 아니다. 후보의 별도 작업 흐름 연결안은 포함하지 않는다.

## 결과와 한계

응답과 읽기 기록은 각 실행자가 작성한 원문 그대로 output에 복사한다. Main은 코드와 실제 후속 대화에 대조하고 comparison.md에 판단을 남긴다. 독립 평가자는 추가하지 않는다.

폴더 밖 자료를 읽지 말라는 지시를 동일하게 제공했지만 시스템 수준 파일 접근 격리는 아니다. 읽기 기록은 자기보고다. 실행별 토큰 사용량은 수집하지 않는다. 각각1회이므로 모델 차이·본문 효과의 안정성이나 실제 사용자 이해 개선을 확정하지 않는다. 운영 스킬·복구 스킬·제품 코드 변경은 하지 않는다.
