conversation.txt의 마지막 사용자 발화에 이어 답한다. 대화 읽기본은 원문과 발화 순서를 보존한다. 질문 대상은2026-09-22의 보존 코드이며 이 폴더에서 현재 앱을 실행하지 않는다.

- project-guide.md와client-guide.md: 당시 질문보다 앞선 Git commit62ce226의 부모에서 가져온 프로젝트 지침. 이 폴더에는 질문에 필요한 자료만 있다. 안내된 다른 문서를 추정하거나 원 저장소로 확장하지 않는다.
- code/auth-interceptor.ts,auth.ts,auth-transport.ts: 질문 직후 실제 도구가 읽은 코드에서 추출. auth.ts는 두 출력의 중첩을 맞춰 연결했다.
- code/consumers.txt: 관련 사용처의 당시 직접 읽기 발췌. 전체 저장소가 아니다.
- skill/SKILL.md와shared/explanation-and-evidence-criteria.md: 이번 응답에 적용할 고정 지침이다. 코드 시점 재연과 별개로 지정된 판본을 사용한다.

제공되지 않은 파일이나 runtime은 확인하지 못한 상태다. 설명을 위해 확인할 자료는 이 폴더 안에서 선택한다. 이 안내는 출력 목차가 아니다.
