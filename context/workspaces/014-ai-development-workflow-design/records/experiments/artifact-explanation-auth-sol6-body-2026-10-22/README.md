# 인증 인터셉터 — GPT-6-sol medium 본문 비교

Luna의 두 응답 차이가 작으면6.0 sol medium으로 다시 시험하라는 사용자 요청에 따른 추가 실행이다. Luna에서는 양쪽 모두 요약 중심이었고 후보의 뚜렷한 개선을 확인하지 못했다.

- 새 worker 두 개에 `gpt-6-sol`, `medium`, `fork_turns=none`을 지정했다. 기존판r36·수정판r91을 각각 한 번 실행한다.
- 앞선6.1-sol 인증 시험의 입력11개를 그대로 복사했다. 두 조건 사이의 유일한 파일 차이는skill/SKILL.md다. conditions.json에 매핑·복사 출처·해시를 보존한다.
- 사용자9의 문법 질문·AI13의 문법 설명·사용자20의 전체 코드와 동작 질문까지 제공했다. 실제 첫 답48과 이후55·73의 사용자 교정, 보완 답66·77, 현재 대화·앞선 모델 결과·기대 답은 주지 않았다.
- 질문 조사를 시작할 때 지정 스킬을 적용하도록 양쪽에 동일하게 지시했다. 자연 선택·발동 시점 효과를 시험하지 않는다. 별도 보고 지침·필수 코드블록·도식·출력 목차도 추가하지 않았다.
- 모델 이외의 실행 조건을 앞선 인증 시험과 맞췄다. 다만 현재 공통 상위 지침과 도구 환경을 포함하므로9월 당시 전체 하네스의 재현은 아니다. 모델·판본별1회이며 안정된 효과나 사용자 이해 개선을 확정하지 않는다.

각 실행의 response.md와read-log.md를 그대로 output에 복사하고 Main의 코드 대조는comparison.md에 분리한다. 읽기 범위 제한은 지시이며 시스템 수준 격리가 아니다. 토큰 사용량은 수집하지 않는다. 운영 스킬·복구 스킬·제품 코드 변경은 포함하지 않는다.
