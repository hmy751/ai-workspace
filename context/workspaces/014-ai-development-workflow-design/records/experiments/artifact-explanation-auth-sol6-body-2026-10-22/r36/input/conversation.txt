코드 블록은 `ruby`로 표시됐지만, 이 코드는 **JavaScript/TypeScript 문법**이에요.

`??=`는 **nullish assignment(널 병합 할당)** 연산자입니다. 왼쪽 값이 `null` 또는 `undefined`일 때만 오른쪽 값을 할당합니다.

```ts
config.sessionId ??= useAuthStore.getState().sessionId ?? undefined;
```

이 줄은 `config.sessionId`가 이미 있으면 그대로 두고, 없으면 auth store의 `sessionId`를 넣습니다. `?? undefined`는 store의 값도 `null`이나 `undefined`일 때 `undefined`를 쓰겠다는 뜻이에요.

대략 이렇게 풀어 쓸 수 있습니다.

```ts
if (config.sessionId === null || config.sessionId === undefined) {
  config.sessionId = useAuthStore.getState().sessionId ?? undefined;
}
```

`||=`와 달리 `??=`는 `""`, `0`, `false`를 **기존 값으로 인정**하고 덮어쓰지 않습니다.

&#x20;     throw error;
