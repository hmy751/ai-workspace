# 현재 목표와 조건

작업에서 생긴 판단과 과정을 보존하고 다시 활용하는 기록 운영안을 만든다. 바로 재개할 목표·상태뿐 아니라 나중에 돌아볼 분석·선택 이유·채택하지 않은 대안·시행착오도 대상이다. 모든 대화를 저장하는 의무는 두지 않는다. Workspace 구성과 읽기 순서, 갱신·보존 방식도 검토 범위이며 기존 배치를 최종안으로 전제하지 않는다.

현재 선택은 **기록 담당 서브에이전트가 대화 원문과 기존 문서를 보고 무엇을 남길지 판단하고 직접 수정하는 방식(A)**이다. Main이 기록 내용을 미리 선별해 전달하는 방식(B)이나 Main이 직접 기록하는 방식(C) 대신 A를 선택했다. 사용자 의도는 기록 판단 자체도 담당자에게 맡기는 것이다.

기존의 지속 추적 방식은 비효율과 토큰 소모 때문에 없애고 스킬로 보완하려는 방향이다. 매번 기록하기보다 마무리하거나 필요할 때 호출하는 형태를 생각하고 있으며, 정확한 호출 조건과 주기는 아직 정하지 않았다. 반복해서 전체 대화를 다시 읽는 비용을 어떻게 줄일지도 구체화할 사항이다.

현재 문서 반영은 기존 Work 작성·갱신 기준을 따른다. 새 Workspace 구성이나 새 운영 원칙을 이번 선택만으로 확정하지 않는다. 비교한 역할과 제안의 채택 범위는 [선택 기록](../../records/2026-10-30-recording-responsibility.md)에 남겼다.
