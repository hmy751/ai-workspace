목록·상세·폼 종합 UX

초안 보존과 조회 복구는 구현됐지만, native 조작과 실제 단절 저장을 포함한 종합 확인은 남아 있습니다.

코드 기준: 제공된 HEAD 0b3b167 스냅샷 · 검토 작성: 2026-10-21 · 이어받은 대화 시점: 2026-10-04

근거 범위 — 이번에 코드·테스트 본문을 직접 대조했습니다. 앱·시뮬레이터·DB·전체 Jest는 실행하지 않았습니다. 대화와 저장 기록의 과거 통과·관찰은 새 실행 결과와 구별합니다. Git 메타데이터가 없어 branch·working tree는 재확인하지 못했습니다.

개선된 작성 흐름을 다시 만들 필요는 없습니다

일정 생성은 연결 상태가 아니라 사용자 행동으로 search/form/change-place 단계를 바꿉니다. 초안 훅은 분기 UI보다 위에서 유지되고 ScheduleForm은 한 분기에서만 장착됩니다. 현재 생성 화면과 회귀 테스트 본문이 과거 폼 숨김·동시 표시 문제에 대응합니다. 다만 native picker·취소 경고 소멸은 이번 정적 확인만으로 확정할 수 없습니다.
