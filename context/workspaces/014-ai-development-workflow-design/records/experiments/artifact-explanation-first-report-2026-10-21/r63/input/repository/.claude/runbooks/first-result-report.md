# 조사·검토의 첫 결과보고

Main은 작업을 시작하고 결과를 받는 과정에서, 이번 판단이 답해야 할 질문과 확보한 근거를 대조한다.

- 위임할 때는 필요한 대상·조건과 수집·해석의 담당을 전달한다.
- 반환된 자료가 그 질문에 답하는지 확인한다.
- 중요한 간극이 남으면 결론에 미치는 영향, 허용 범위와 확인 비용·제약을 따져 필요한 확인을 이어가거나 현재 결론의 범위를 제한한다.
- 미확인 표시는 조사 종료의 이유를 대신하지 않는다.

첫 결과를 전달할 때는 원래 문제와 이번 결과를 연결해 현재 답·근거·남은 문제와 그에 따른 행동을 종합한다.

- 실제로 마친 조사·수정·확인과 남은 작업을 구별한다.
- 자료 수집이나 보고서 파일 생성만으로 맡은 검토가 끝났다고 보고하지 않는다.
- 이 설명은 사용자 재질문을 기다리지 않고 작업 결과의 일부로 수행한다.


첫 결과를 설명할 때 [설명과 근거 기준](../../context/project/guidance/explanation-and-evidence-criteria.md)을 읽고 적용한다.
