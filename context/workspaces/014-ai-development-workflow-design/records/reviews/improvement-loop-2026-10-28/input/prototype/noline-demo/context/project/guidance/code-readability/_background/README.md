# 인증 표현 가이드의 형성 자료

이 폴더는 [인증 코드의 이름과 완료 표현](../INDEX.md)이 제품 가이드로 남은 이유, 개인 기준과의 책임 경계, 이름 수정과 동작 변경을 구별한 논의·근거를 보존한다. 현재 가이드를 더 정확히 이해하거나 표현·완료 계약을 재검토할 때 당시 조건을 복원하는 자료다.

일상적인 이름·callback·안내 판단에는 본문을 읽는다. 아래 작성 논의에 등장하는 후보 이름이나 과거 제안은 모든 작업의 현재 의무가 아니다.

| 확인할 질문 | 읽을 부분 |
| --- | --- |
| 개인의 명명 기준과 별개로 이 제품 가이드가 필요한 이유는 무엇인가 | [제품이 표현할 결과의 맥락](context.md#제품이-보장하는-결과를-알아야-표현을-판단할-수-있다) |
| 왜 최종 함수명과 코드 발췌는 current에 두었는가 | [입력과 결과를 구별한 기록](records/2026-10-19-product-expression-boundary.md), [관련 발췌](evidence.md#판단-조건과-현재-이름을-나눈-작성-논의) |
| 조회 대기나 오류 처리를 이름 개선과 함께 바꿔야 하는가 | [표현과 동작의 구별](context.md#이름-개선이-필요한-장면과-동작-변경이-필요한-장면), [제품의 비동기 기준](evidence.md#비동기-표현의-제품-기준) |
| 개인 기준 보완 뒤 Project까지 함께 고쳤던 이유를 재검토하려는가 | [개인 기준 소유의 발췌](../../../../personal/development/naming-and-completion/_background/evidence.md#개인-기준의-소유), [당시 관리 책임 기록](../../../../personal/development/naming-and-completion/_background/records/2026-10-19-personal-ownership.md) |

인증 저장·실패·대기의 계약 자체는 [인증 계약 본문](../../authentication-and-session/INDEX.md)이 소유한다. 공통 책임 정정과 개인 기준의 원문을 이 폴더에서 다시 관리하지 않는다.
