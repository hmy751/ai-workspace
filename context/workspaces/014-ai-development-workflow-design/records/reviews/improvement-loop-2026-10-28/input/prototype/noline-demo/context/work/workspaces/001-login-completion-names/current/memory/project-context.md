# 이번 작업이 선택한 Project 맥락

[Project 입구](../../../../../project/README.md)에서 인증 완료가 쟁점인 문서를 선택한다. 제품 약속을 이해하기 위해 개인 기준의 원문을 먼저 읽을 필요는 없다.

- [기기 세션과 연속성](../../../../../project/common/device-session/INDEX.md): 같은 계정의 로컬 작업을 보존하고 인증 수단과 조회 결과를 구별한다.
- [인증·세션 계약](../../../../../project/guidance/authentication-and-session/INDEX.md): 저장·상태 적용 순서와 인증 이후 조회 실패의 경계를 지킨다.
- [인증 가독성](../../../../../project/guidance/code-readability/INDEX.md): 이름·callback·안내와 호출자가 기대할 결과를 대조한다.
- [현재 인증 흐름](../../../../../project/current/authentication-flow/INDEX.md): 실제 예제의 구현·검사 위치와 확인 범위를 읽는다.

이번 이름 선택으로 인증 계약을 바꾸지 않는다. 코드와 계약이 다르면 단순 표현 수정인지 실제 동작 수정이 필요한지 다시 판단한다. 이 목록은 사람용 현재 선택이며, 설치되지 않은 Recover가 읽었다는 실행 증거가 아니다.

연결된 가이드는 현재의 제품 계약·판단 조건이고, current는 선택 후 함수명·실제 코드·지원 범위를 설명한다. 최초 판단 입력은 [보존된 시나리오](../../source/scenario-input.md)와 당시 기록에서 구별한다. 그 입력의 재구성 해설은 [walkthrough](../../../../../../../walkthrough.md)에 있다. 현재 가이드나 결과를 최초 작업자에게 그대로 주었다는 뜻은 아니다.
