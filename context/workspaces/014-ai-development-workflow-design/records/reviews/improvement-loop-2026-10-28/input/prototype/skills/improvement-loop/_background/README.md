# Improvement Loop의 형성 자료

[실행 본문](../SKILL.md)은 현재 세션에서 경험·현재 내용을 개선으로 연결하는 수행을 소유한다. 이 층은 왜 그 범위와 배치를 택했는지 보존한다.

- 루프를 현재 Main과 별도 호출 본문으로 둔 이유, Personal·반영 책임·미확인의 관계: [형성 맥락](context.md).
- 직접 사용자 발화와 외부 자료에서 가져온 관점·가져오지 않은 절차: [근거](evidence.md).
- 네 묶음 합의를 실제 파일로 만든 선택과 남은 확인: [구체화 기록](records/2026-10-28-prototype.md).

원래 전체안의 독립 개선 리뷰 뒤 사용자와 합의했고, 이번 실행 파일은 Main이 작성·대조했다. 이 판본의 새 독립 리뷰·실제 운영 효과를 확인한 자료는 아니다.

명칭과 전체 목적을 다시 볼 때는 [이름 변경 기록](records/2026-10-28-naming.md)을 읽는다.
