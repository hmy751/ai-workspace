# Context의 책임과 관리 원칙을 형성한 자료

이 층은 [context 진입 본문](../README.md)의 책임 구분, [본문 관리 원칙](../CONTENT-POLICY.md), [체계 지침의 역할과 구성](../SYSTEM-GUIDANCE.md)을 형성한 의도·배경·중요한 선택·근거를 보존한다. 현재 방향을 이해하고 경계나 관리 방식을 수정할 때 이유를 복원하기 위한 자료이며, 평소 각 본문을 적용하는 데 먼저 읽을 묶음은 아니다. 책임·위치의 맥락은 이 폴더에서, 본문·형성 자료의 관리 방식은 `content-policy/`, 체계 지침의 구별과 진입 책임은 `system-guidance/`에서 찾는다.

| 알고 싶은 것 | 읽을 범위 |
| --- | --- |
| 같은 context 안에 두면서 내용 책임은 왜 나누나 | [현재 형성 맥락](context.md) |
| 별도 개인 기준 호스트와 Project의 직접 의존은 왜 바뀌었나 | [책임과 위치를 정정한 기록](records/2026-10-19-ownership-and-local-context.md) |
| 독립 책임·로컬 위치에 관한 실제 표현은 무엇이었나 | [사용자 발췌](evidence.md) |
| 개인 기준 변화가 Project까지 자동으로 번지지 않게 한 이유는 무엇인가 | [기존 소유 기록](../personal/development/naming-and-completion/_background/records/2026-10-19-personal-ownership.md), [그 발췌](../personal/development/naming-and-completion/_background/evidence.md#개인-기준의-소유) |
| 왜 본문과 형성 자료를 나누고, 어느 문서까지 이 방식을 적용하나 | [관리 정책의 형성 자료](content-policy/README.md) |
| 왜 체계 지침을 구별하며 진입 본문과 상세 지침을 어떻게 함께 두나 | [체계 지침의 형성 자료](system-guidance/README.md) |
| 일상 읽기와 지정 본문 반영은 왜 다른 방법으로 연결했나 | [공통 사용 방법의 형성 자료](usage/README.md) · [반영 스킬의 형성 자료](../../../skills/context-update/_background/README.md) |

기록에는 대체된 제안과 당시 유보가 포함된다. 현재 책임은 context와 각 영역의 본문에서 읽고, 과거 구성을 최신 요구로 적용하지 않는다. 공통 보존·갱신 원칙은 [CONTENT-POLICY](../CONTENT-POLICY.md)가 소유한다.
