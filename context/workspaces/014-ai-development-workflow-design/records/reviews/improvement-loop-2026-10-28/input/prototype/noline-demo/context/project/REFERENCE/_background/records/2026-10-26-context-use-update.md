# 2026-10-26 — 공통 사용·반영과 Project 관리의 연결

[Project 읽기 기준](../../reading.md)과 [관리 계약](../../../MAINTENANCE.md)의 변경 기록이다.

질문별 본문 선택·유효한 읽기 재사용·추가 탐색·원래 과업 복귀를 context 공통 USAGE로 옮기고, Project 읽기 기준에는 인증의 저장·상태 적용·조회 완료와 실제 소비자의 대기·실패 경계를 대조하는 제품별 판단을 남겼다.

관리 계약은 지정 본문 반영의 공통 수행을 context-update에 연결하면서 계속 남길 내용·권한·제품 의미의 충분성을 소유한다. 구현 변화가 있었다는 사실만으로 Project를 편집하지 않고, 여러 작업의 이해·판단에 필요한 지속 의미가 바뀌었는지 먼저 본다. 필요한 현재 지원 사실과 이번 구현·검사 진행은 구별한다.

계약·가이드에 같은 현황이 적혀 있으면 허용된 반영에서 함께 정정할 수 있지만, 데모에 문장이 존재한다는 사실로 그 내용의 소유 적합성을 확정하지 않는다. 관련 Work 선택·output의 영향은 확인해 해당 담당에게 연결하며 한정 Project 반영 권한을 전체 Work 수정권으로 확대하지 않는다.

이 변경은 [사용자 정정과 제안·검토 방향](../../../../../../skills/context-update/_background/evidence.md)을 현재 관리 본문에 적용한 것이다. 이전 구성·소유 정정의 이유는 유지하며, 제품 변경·검증 성공이나 운영 자동화의 결과로 기록하지 않는다.
