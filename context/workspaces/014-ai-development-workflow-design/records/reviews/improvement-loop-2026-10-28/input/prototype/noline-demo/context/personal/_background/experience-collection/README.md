# Personal 경험 모음의 형성 자료

[Personal](../../README.md)은 개인 기준과 경험·해석·열린 후보의 상위 경계를, [경험 모음](../../experience/README.md)은 주제 진입을 소유한다. 이 층은 범위를 넓히고 현재 구성을 선택한 이유를 맡는다.

- 왜 개인 기준과 경험을 함께 두되 지위를 구별했는지: [형성 맥락](context.md).
- 사용자 원문·Work 정정·네 묶음 합의: [루프의 공통 형성 근거](../../../../../skills/improvement-loop/_background/evidence.md). 동일 발췌를 여기 복제하지 않는다.

역사적 경험의 사실·해석·후보는 각 경험 주제 본문에 있으며 이 형성 자료가 후보 수집함을 대신하지 않는다. 기존 개발 기준의 형성 경위는 각 개발 주제의 자료를 유지한다.
