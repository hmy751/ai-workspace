# 04-02 — 시험 원문 보존과 현재 기록 점검

사용자가 시험 파일을 커밋하지 않은 이유와 기록 갱신 상태를 물었다. Main은 이전 커밋 요청을 통합·삭제까지로 좁혀 해석한 뒤 후속 시험을 미커밋 상태로 둔 처리 미흡을 인정했다. 이번에는 실제 저장 파일을 대조하고 오래된 현재 문장을 정리한 후,04-02 스킬 보완·시험·평가·현재 기록을 함께 커밋할 범위를 확인했다.

네 묶음·여덟 실행의 입력 사본1352개와 inventory 해시를 대조했다. 모든 읽기 이벤트의 내용 해시와 응답 해시가 일치했고, 각 A·B 파일은 해당 실행의 response.md와 바이트 동일했다. 유효한 여섯 실행의 선택 파일 조각 누락은0이며, 최초 무효 시험의70행 누락은 그대로 확인됐다. 현재 explain 본체·두 상세가 마지막 시험 입력 판본과 동일한 것도 확인했다. [기계 검증 내역](receipts/skill-experiments/2026-10-24-network-comparison-preservation.json)에 실행별 수치·해시를 남겼다.

이 검사는 보존 파일의 동일성과 기존 읽기 절차 결과를 대조한 것이다. 모델의 내부 이해, 실제 제품 실행이나 OS 수준 접근 격리를 새로 검증하지 않았다. 실험 입력·응답·평가는 임시 경로 없이 저장소 안에 남아 있고, 조건 파일의 당시 runtime 경로는 실행 이력이다. 원응답의 과거 저장소 링크·표현은 원문성을 위해 수정하지 않았다.

## 갱신한 현재 기록

Ticket04-02, current/index·state, output/index와 records 색인은 이미 최신 비교·평가를 가리키고 있었다. 다만 explain의 형성 맥락에 수정 후 시험 미실행 문장이 남아 있어 수정 후 관찰과 인과 한계로 갱신하고 가까운 evidence에 사용자 반응·자료 식별자를 보강했다. output의6.1 결과는 최신 결과가 아니라 수정 전 확인으로 표시했다. 수정 직후 기록의 당시 미실행·미커밋 문구는 후속 기록 연결로 시점을 구별했다. 날짜별 과거 판단과 실험 원문은 새 결론으로 덮어쓰지 않았다.

스킬의 실행 내용은 추가 수정하지 않았다. 형성 자료 변경을 반영해 viewer를 다시 생성했다. 첫 검사에서 새 evidence 절의 앵커 불일치를 발견해 파일 링크로 바로잡고 재검사했다. 현재 작업 트리에서 다른 작업의 변경은 d4fdd7e에 이미 커밋돼 있었으며, 이번 범위는 그 이후 남은04-02 변경과 보존 자료다. 기존 사용자 작업을 되돌리거나 원본 source를 수정하지 않는다.

현재 남은 것은 수정 스킬의 실제 설명 효과에 관한 판단이며04-02는 계속 열려 있다. 문구·모델·추론 수준·생성 편차의 인과를 확정하지 않고 새 시험이나 스킬 수정은 자동 시작하지 않는다. 커밋 성공 여부와 식별자는 실제 Git 결과에서 확인한다.


## 커밋 전 최종 검사

viewer 재검사는 원문·해시 일치와 누락 경로/앵커0으로 통과했다. staged diff 검사는 보존 입력의 worker-change.patch와 conversation.txt 사본16개에서만 원래 공백·끝 빈 줄 경고1112건을 반환했다. 입력 해시와 원문 보존을 위해 이 공백은 수정하지 않았으며, 새 설명 지침·기록 등 보존 입력 밖의 경고는0이었다. 커밋 대상은04-02 관련1450개 파일이며 대부분 동일 시험 자료의 실행별 보존 사본이다. 다른 작업 경로가 섞이지 않았음을 확인했다.
