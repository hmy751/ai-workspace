# 개념·입출력 계약

**인증 적용 완료**는 이 예제에서 계정·여행 귀속을 확인하고 저장 성공 뒤 공개 세션 상태를 바꾼 결과다. **조회 요청**은 이후 최신 데이터를 가져오려는 시도이며, 조회 결과나 화면 반영까지 마쳤다는 뜻이 아니다.

서비스는 인증 응답, 주어진 진행 작업 대기, Store 적용을 기다린다. wrapper는 인증 적용 뒤 조회를 요청하고 `onSignedIn`으로 인증 완료를 전달한다. 조회 Promise의 실패와 요청 자체의 동기 오류는 `onRefreshError`가 받는다. 이 callback은 정상 반환한다고 가정한다.

Store 저장이 실패하면 이전 저장값이 남는다는 어댑터 계약 안에서 상태를 보존한다. 디스크 일부만 써진 경우의 복구, 동시 세션 변경, 실제 queue 조율은 이 예제의 보장에 포함되지 않는다.

지속 제품 계약은 [Project 인증 가이드](../../../../../../project/guidance/authentication-and-session/index.md)가 소유한다. 이 Work는 그 계약이 이번 코드·소비자의 입출력에 어떤 제한을 주는지 선택해 사용한다.
