# 본문 형식을 정한 자료

| 확인할 질문 | 읽을 범위 |
| --- | --- |

| 왜 CONTENT-POLICY에 넣지 않고 별도 문서로 두었나 | [위치의 선택](context.md#위치와-범위의-선택) |
| 왜 처음에는 기준 본문에만 적용하나 | [위치의 선택](context.md#위치와-범위의-선택) |
| 사용자는 실제로 무엇을 보고 어떻게 판단했나 | [사용자 발화](evidence.md#사용자-발화) |
