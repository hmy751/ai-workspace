# 기기 세션과 같은 계정의 작업 연속성

서버 인증 수단과 기기에 남은 사용자의 여행 데이터는 관련되지만 같은 정보가 아니다. 같은 계정으로 다시 로그인할 때는 기존 로컬 여행 데이터를 유지하며 인증을 복구한다. 다른 계정의 데이터나 소속을 확인하지 못한 데이터를 로그인 편의를 위해 자동 폐기하지 않는다.

`signed-in`은 사용할 인증 수단을 보유한 상태다. 모든 원격 요청이 성공한다거나 모든 화면이 최신 데이터를 표시한다는 뜻은 아니다. 기기 저장과 공개 상태를 일관되게 바꾸는 순서·실패 처리는 [인증·세션 계약](../guidance/authentication-and-session.md)이 맡는다.

화면의 Query 데이터는 별도의 조회 결과다. 인증을 복구한 뒤 조회를 갱신할 수 있지만, 그 조회 실패가 이미 끝난 인증 저장을 과거의 실패로 바꾸지는 않는다. 사용자에게 필요한 복구 동작은 실패한 책임에 맞게 정한다.

이 제품 의미를 코드 예시에서는 계정 ID와 여행 목록으로 표현한다. 실제 여행 데이터 모델이나 DB·queue 전체를 이 간단한 모델로 대체한다는 뜻은 아니다. 현재 실행 범위는 [인증 흐름](../current/authentication-flow.md)에서 확인한다.
