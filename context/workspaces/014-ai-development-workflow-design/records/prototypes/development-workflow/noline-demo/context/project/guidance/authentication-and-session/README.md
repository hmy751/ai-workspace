# 인증 완료·실패와 후속 조회의 계약 — 구성과 읽기

[시작 본문](index.md)은 저장·공개 순서와 사건별 실패·대기·callback의 계약를 현재 사용할 내용으로 설명한다. 형성 자료는 이 본문을 만들게 된 목적·배경·선택과 그 근거를 가까이 보존해, 이후 의미를 더 정확히 이해하거나 수정할 때 당시 조건을 복원하게 한다.

현재 내용의 적용에는 `index.md`를 읽는다. 제품 원자료에서 가져온 경계와 데모에서 추가한 선택을 구별하거나 대기 계약을 바꾸려는 경우가 필요하면 [형성 자료 안내](background/README.md)에서 해당 질문의 맥락·기록·근거를 고른다. 이 문서는 구성 안내를, 본문은 현재 설명을 맡는다.

의미·조건을 바꾸는 작업자는 관련 형성 자료를 대조하고 영향받는 본문·현재 맥락과 들어오는 읽기 경로를 함께 맞춘다. 실제 제품 계약, 이 데모의 선택, 구현 사실의 지위를 보존한다. 구성·보존·갱신의 공통 기준은 [관리 원칙](../../../CONTENT-POLICY.md)에 있다.
