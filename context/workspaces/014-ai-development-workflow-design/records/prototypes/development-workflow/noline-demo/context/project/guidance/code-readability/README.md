# 인증 코드의 이름과 완료 표현 — 구성과 읽기

[시작 본문](INDEX.md)은 Store·서비스·callback·안내를 소비자가 기대할 결과와 대조하는 개발 판단를 현재 사용할 내용으로 설명한다. 형성 자료는 이 본문을 만들게 된 목적·배경·선택과 그 근거를 가까이 보존해, 이후 의미를 더 정확히 이해하거나 수정할 때 당시 조건을 복원하게 한다.

현재 내용의 적용에는 `INDEX.md`를 읽는다. 개인 기준과 제품 가이드의 역할, 이름 수정과 동작 변경을 구별한 이유가 필요하면 [형성 자료 안내](_background/README.md)에서 해당 질문의 맥락·기록·근거를 고른다. 이 문서는 구성 안내를, 본문은 현재 설명을 맡는다.

의미·조건을 바꾸는 작업자는 관련 형성 자료를 대조하고 영향받는 본문·현재 맥락과 들어오는 읽기 경로를 함께 맞춘다. 실제 제품 계약, 이 데모의 선택, 구현 사실의 지위를 보존한다. 구성·보존·갱신의 공통 기준은 [관리 원칙](../../../CONTENT-POLICY.md)에 있다.
