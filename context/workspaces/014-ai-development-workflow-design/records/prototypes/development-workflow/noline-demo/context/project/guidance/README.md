# 제품 개발 계약과 적용

[인증·세션 계약](authentication-and-session/INDEX.md)은 인증 저장·상태 공개·조회 후속 실패를 바꿀 때 지킬 경계를, [인증 가독성](code-readability/INDEX.md)은 이름·callback·안내가 소비자의 기대와 맞는지 판단하는 기준을 제공한다. common의 제품 의미와 current의 구현 사실을 필요한 만큼 함께 읽는다.

이 층의 역할과 다른 층의 관계는 [Project 입구](../README.md)에서 찾는다. 실제 주제를 담당하는 본문을 읽고, 구성·갱신 작업일 때만 관리 기준으로 내려간다.
