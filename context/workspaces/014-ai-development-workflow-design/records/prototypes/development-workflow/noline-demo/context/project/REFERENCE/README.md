# Project 본문을 만들고 읽는 기준

이 영역은 제품 내용이 아니라 그 내용을 구성하고 사용하는 판단 기준이다.

- [읽기와 적용](reading.md): 관련 작업에서 필요한 본문을 선택하고 실제 계약·예외를 적용할 때
- [내용 구성과 분리](composition.md): 새 본문을 작성하거나 기존 내용을 나누고 합칠 때

갱신 시점과 권한·영향·완료는 [관리 계약](../MAINTENANCE.md)이 맡는다. 일반 제품 작업에 이 문서 전체를 기본 입력으로 붙이지 않는다.

이 읽기·구성 기준과 관리 계약이 형성된 배경을 확인하거나 그 이유를 재검토할 때는 [형성 자료 안내](background/README.md)를 읽는다. 형성 자료는 기존 문서의 보조 근거이며 현재 읽기·구성·갱신 본문을 대신하지 않는다.
