# 계약과 수명

공통 입력·반환·오류의 의미, 상태·타이머·이벤트의 수명, 지원 범위 안의 정확성을 판단하는 주제다. 현재 적용할 기준과 조건별 사례가 본문을 이룬다. 형성 자료는 그 기준을 만든 의도·논의·선택을 복원하는 자료이며, 이 주제에는 별도로 확인해 보존한 형성 자료가 아직 없다.

- 공개한 계약을 믿고 호출할 수 있는지, 책임을 옮기면 시간·실패·종료 의미가 달라지는지 판단할 때는 [시작 본문](index.md)을 읽는다.
- 같은 타입이나 호출 모양인데 선택이 달라지는 이유가 필요하면 [사례 본문](index.cases.md)에서 fetcher·silent·Toast·이벤트 Hook 중 관련 장면을 고른다. 현재 판단을 위한 조건별 비교이며 실행 완료 기록이 아니다.

사례는 기존 문서에 보존된 코드 관찰과 명시한 가정에 근거한다. 이 묶음을 구성하면서 원래 구현을 다시 조사하거나 제품에서 실행한 것은 아니다. 특히 타이머 이전·null 정책·새 지원 범위는 당시 확정하지 않은 선택으로 유지한다. 형성 의도가 필요한 수정에서는 이 사례만으로 과거 의도를 추정하지 않는다.

표현과 동작 중 무엇을 고칠지 함께 판단해야 하면 [이름·책임·완료](../naming-and-completion/index.md)를 읽는다. 주제의 구성·보존·갱신은 [공통 관리 원칙](../../../CONTENT-POLICY.md)을 따른다.
