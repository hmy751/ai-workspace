# 제품 선택의 근거

중요한 제품 선택의 이유·기각안·재검토 조건을 보존하는 위치다. 현재 답은 원칙적으로 common·guidance·current의 해당 본문이 소유한다.

현재 이 demo가 새로 확정해 이곳에 남긴 제품 공통 결정은 없다. 한 Work에서 선택한 `signInAndRequestRefresh` 이름과 비대기 예제 구현의 이유는 [Work 작성 기록](../../work/workspaces/001-login-completion-names/records/2026-10-19-02-implementation.md)에 있다. 파일을 채우기 위해 그 선택을 제품 전체 결정으로 올리지 않는다.
