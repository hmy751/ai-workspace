# 공통 제공과 사용처 선택

컴포넌트·Hook·업무 흐름에서 함께 보장할 동작과 사용처마다 남길 선택을 판단하는 주제다. 현재 적용할 기준과 조건별 사례를 같은 본문 층에 둔다. 기준을 만든 의도·논의·선택을 복원하는 자료는 형성 자료이며, 이 주제에는 별도로 확인해 보존한 형성 자료가 아직 없다.

- 공통으로 맡길 범위, 부품 교체, 같은 업무 흐름의 관련 개선을 판단할 때는 [시작 본문](index.md)을 읽는다.
- 기준만으로 선택 차이가 불분명하면 [사례 본문](index.cases.md)에서 Field의 배치·입력 교체, Container의 오류 표시, 주문 후처리 중 관련 장면을 고른다. 사례는 현재 기준을 적용하기 위한 설명이며 과거 결정 기록이 아니다.

사례에 있는 코드 관찰과 설명용 가정의 지위는 각 절에 남겨 두었다. 이 묶음을 구성하면서 외부 UI 템플릿을 다시 조사하거나 원래 작성자의 의도를 확인한 것은 아니다. 기준의 형성 이유를 재검토하는 데 부족한 자료는 새 근거를 확보해 보완하며, 사례의 가정을 과거 선택으로 바꾸어 쓰지 않는다.

다른 판단이 필요하면 [개발 판단](../README.md)에서 관련 주제를 고른다. 주제의 구성·보존·갱신은 [공통 관리 원칙](../../../CONTENT-POLICY.md)을 따른다.
