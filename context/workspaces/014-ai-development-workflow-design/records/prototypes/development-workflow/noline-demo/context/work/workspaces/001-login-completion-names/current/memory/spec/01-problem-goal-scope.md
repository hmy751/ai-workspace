# 문제·목표·범위

부여한 초기 장면의 `loginAndRefresh`와 `onCompleted`, ‘로그인과 화면 갱신 완료’라는 안내는 실제로 기다리는 인증 적용보다 넓은 완료를 암시한다. 목표는 호출자가 인증 저장·상태 적용과 조회 갱신 완료를 혼동하지 않도록 표현과 동작의 관계를 드러내는 것이다.

메모리 기반 세션 Store, 로그인 서비스·wrapper, Login·Reauth 소비자와 직접 검사를 포함한다. 기존 실제품의 개명 작업이 아니라 초기 가정에서 출발해 새 실행 예제를 작성한 작업이다. 이름 유지·설명 보완도 가능한 대안이며 개명 자체가 목표는 아니다.

실제 Noline의 UI·서버·디스크 저장·DB/queue 조율이나 자동 Context Harness 설치는 포함하지 않는다. 초기 장면의 원문은 [source](../../../source/scenario-input.md), 현재 예제 위치는 [output](../../../output/index.md)에 있다.
