# 관련 Project 본문을 읽고 적용하기

제품에 관한 질문에서 [Project 입구](../README.md)의 주제별 경로를 고른다. 질문별 선택·유효한 읽기 재사용·추가 탐색과 원래 과업 복귀는 [공통 사용 방법](../../USAGE.md)을 따른다. 이 문서는 그 방법을 Project의 제품 계약과 현재 지원 범위에 적용한다.

선택한 본문에서 맡은 의미·적용 조건·예외를 이해한 뒤 이번 변경이 보존하거나 바꿀 계약과 연결한다. 인증의 이름을 다룬다면 저장·상태 적용과 조회 완료의 차이를 먼저 파악하고 실제 코드·소비자의 대기·실패 경계를 대조한다. 관련 없는 제품 주제까지 자동으로 펼치지 않는다.

계약·guidance가 약속하는 동작과 current가 설명하는 현재 지원 범위를 구별한다. 예를 들어 인증 적용 뒤의 조회를 기다리는 소비자가 생겨도 모든 로그인의 공통 완료 약속이 바뀐 것은 아니다. 실제 사용처·대기·실패 동작과 유효한 제품 결정을 대조해 이번 변경에 적용할 범위를 판단한다.

본문이 자기 의미를 충분히 설명하지 못하거나 지속 설명에 변화가 필요하면 근거와 함께 [관리 계약](../MAINTENANCE.md)으로 연결한다. 읽기 자체로 수정 권한을 얻지는 않는다. 원자료 기억이나 링크 목록으로 빈 제품 계약을 대신하지 않으며, 문서 존재와 실제 이해·적용을 구별한다.
