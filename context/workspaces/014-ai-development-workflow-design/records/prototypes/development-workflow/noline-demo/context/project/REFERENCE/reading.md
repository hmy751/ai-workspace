# 관련 Project 본문을 읽고 적용하기

작업의 질문에서 시작해 [Project 입구](../README.md)의 주제별 경로를 고른다. 폴더 순서대로 전체를 읽는 방식은 요구하지 않는다. 이미 읽은 계약으로 판단할 수 있고 변화 신호가 없다면 다시 읽는 절차를 반복하지 않는다.

선택한 본문에서 맡은 의미·적용 조건·예외를 이해한 뒤 이번 변경이 보존하거나 바꿀 계약과 연결한다. 인증의 이름을 다룬다면 저장·상태 적용과 조회 완료의 차이를 먼저 파악하고 실제 코드·소비자의 대기·실패 경계를 대조한다. 관련 없는 제품 주제까지 자동으로 펼치지 않는다.

문서와 코드가 다르면 현재 사실과 제품 요구를 구별한다. 최근 문서나 코드를 자동 우선하지 않으며, 근거가 부족한 제품 선택만 결정권자에게 확인한다. 읽기 자체가 파일 변경 권한을 추가하지 않는다.

본문이 자기 의미를 충분히 설명하지 못하면 그 부족함을 드러내고 [관리 계약](../MAINTENANCE.md)으로 이어간다. 원자료 기억이나 링크 목록으로 빈 계약을 대신하지 않는다. 문서가 존재하는 사실과 실제 이해·적용 효과는 구별한다.
