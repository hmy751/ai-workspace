# 작업물 이해 브리핑의 형성 자료

이 묶음은 기존 작업물을 이해시키는 책임이 왜 필요했고, 조사·구조 표현·판정 경계를 어떤 이유로 선택했는지 복원한다. 실행은 [SKILL.md](../SKILL.md)가 맡고, 이 자료는 목적 확인·의미 변경·과거 선택 재검토 때 필요한 부분만 읽는다.

현재 SKILL.md는04-02에서 먼저 작성했다가 보류한 수정안이다. 아래는 그 수정안 전체의 채택 이유가 아니라 **수정 전 스킬의 형성 배경과 이후 연결 경위**다.

| 수정할 때의 질문 | 읽을 곳 |
| --- | --- |
| 첫 보고 전에 호출하는 대안은 검토했는가, 값 예시는 왜 필요했는가 | [호출 시점의 대안](context.md#호출-시점을-포함해-검토했던-대안), [당시 예시의 차이](context.md#당시-예시가-보여-주려던-설명의-차이) |
| 어떤 문제를 해결하려 했고 왜 역할·실제 연결·근거를 함께 설명하는가 | [형성 맥락](context.md) |
| 왜 고정 도식·전체 조사·최종 판정으로 넓히지 않았는가 | [형성 맥락의 선택 이유](context.md#설명-방식을-이렇게-정한-이유), [원문 근거](evidence.md) |
| 호출·조건부 보강·Spec/Ticket·Maintain 연결은 언제 어떤 이유로 생겼는가 | [형성 경위](records/2026-10-21-original-formation.md) |
| 당시 사용자 선택·작성자 해석·검증 한계를 직접 대조하려는가 | [발췌와 출처](evidence.md) |

본문이나 책임을 바꿀 때는 [스킬 본문 관리 정책](../../SKILLS-CONTENT-POLICY.md)을 함께 적용한다. 형성 자료를 일상 브리핑의 추가 필독 절차로 만들지 않는다.
