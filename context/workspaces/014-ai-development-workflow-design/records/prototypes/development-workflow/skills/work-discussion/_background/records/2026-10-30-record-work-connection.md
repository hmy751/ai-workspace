# Record Work로 작업 기록을 연결한다

2026-10-30. 사용자는 기존 자동 Maintain을 없애고 원문에서 의미를 판단해 직접 수정하는 서브를 필요할 때 호출·재사용하는 방식을 선택했다. 실행 본문의 Work 기록 경로를 record-work와 대상 작성·갱신 기준으로 연결했다.

Development의 전체 영향·완료 판단, 사용자 요청의 improvement-loop, Personal·Project의 context-update 반영 책임은 유지한다. Work 기록을 위해 새 Work나 새 개선 루프를 강제하지 않는다. 기존 Main 직접 기록 또는 자동 Maintain 보존 문장은 이전 판본의 선택이며 새 연결과 구별한다.

역할·입력·최소 사용자 근거는 [record-work 형성 자료](../../../record-work/_background/README.md)에서 찾는다. 스킬의 실제 호출·문서 반영과 장기 효과는 구별하며 설치만으로 효과를 주장하지 않는다.
