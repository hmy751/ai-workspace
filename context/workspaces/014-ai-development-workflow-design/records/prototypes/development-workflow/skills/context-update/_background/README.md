# Context Update의 형성 자료

[실행 본문](../SKILL.md)이 지정된 Personal·Project 반영을 어떻게 수행할지 설명하고, 이 층은 왜 그 범위와 책임을 택했는지 보존한다. 목적을 더 정확히 이해하거나 호출·쓰기 범위·종료를 수정할 때 필요한 자료를 고른다.

- 내용 소유와 반영 수행, Main 검토와 한정 반영을 나눈 이유: [형성 맥락](context.md).
- 기존 update의 기능을 현재 workflow와 연결한 변경 범위: [적용 기록](records/2026-10-26-bounded-context-update.md).
- 구현자의 제안·Main 검토, Project 내용 선별, 루프 연결에 대한 사용자 원문과 외부 고정판: [근거](evidence.md).

공통 읽기와 반영의 파일 형태를 나눈 잠정 선택은 [USAGE 형성 자료](../../../noline-demo/context/_background/usage/README.md)에서 한 번 관리한다. 과거 후보나 사용자 유보를 현재 실행 권한과 혼동하지 않는다.
