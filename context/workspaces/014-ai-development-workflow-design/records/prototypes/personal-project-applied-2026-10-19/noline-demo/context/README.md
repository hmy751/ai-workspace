# noline-demo context

> 예시 Project의 내용·작업 맥락을 나눈 실제 문서 배치다.

[project](project/README.md)는 여러 작업이 함께 사용하는 제품 의미·개발 기준·현재 연결을 소유한다. [work/workspaces/login-completion-names](work/workspaces/login-completion-names/README.md)는 이번 이름·완료 표현 정리의 요구·현재 상태·선택·검토 기록을 소유한다.

Project의 제품 의미·개발 계약·현재 연결은 각 담당 문서에서 이해할 수 있게 설명한다. Work의 요구와 판단 결과는 이번 작업의 맥락이며, 그 자체로 지속할 제품 계약이 되지는 않는다.

이번 예시는 Project와 한 Work의 내용만 채웠다. recover·maintain·verify 장치나 Workspace 공통 형식 전체의 설치를 뜻하지 않는다.
