# 기기 세션과 같은 계정의 작업 연속성

> 이 시안에서 사용하는 제품 의미의 발췌다. 실제 Noline의 모든 세션 상태·예외를 담은 문서는 아니다.

여행 앱에서 서버 인증 수단과 기기에 남은 사용자의 여행 데이터는 관련되지만 같은 정보가 아니다. 같은 계정으로 다시 로그인할 때는 기존 로컬 데이터를 유지하며 인증을 복구한다. 다른 계정의 데이터나 소속을 확인하지 못한 데이터를 로그인 편의를 위해 자동 폐기하지 않는다.

`signed-in`은 사용할 인증 수단을 보유한 상태다. 모든 원격 요청이 반드시 성공한다거나 모든 화면이 최신 데이터를 표시한다는 뜻은 아니다. 기기 저장과 공개 상태를 일관되게 바꾸는 개발 계약은 [인증 가이드](../guidance/authentication-and-session.md)가 맡는다.

화면의 Query 데이터는 별도의 조회 결과다. 인증을 복구한 뒤 조회를 갱신할 수 있지만, 조회 실패가 이미 끝난 인증 저장을 과거의 실패로 바꾸지는 않는다. 이 관계를 유지하는 순서·실패 처리는 인증 가이드에서 정한다.
