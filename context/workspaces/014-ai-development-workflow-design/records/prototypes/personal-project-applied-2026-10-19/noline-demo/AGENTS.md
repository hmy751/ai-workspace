# noline-demo 작업 진입 — 가상 문서

이 파일은 문서 적용을 보여 주는 예시이며 실제 Noline이나 바깥 ai-workspace의 실행 지침이 아니다. 제품 코드·설치된 skill·자동 Harness는 포함하지 않는다.

작업을 받으면 지정된 Work README에서 목표·현재 단계·범위를 확인하고 [Project README](context/project/README.md)에서 관련 기준과 계약을 고른다. 작업에 필요한 본문과 코드·사용처를 대조하며 모든 Project 문서를 매번 입력으로 추가하지 않는다.

이번 예시 작업은 [로그인 완료 표현 정리](context/work/workspaces/login-completion-names/README.md)다. 구현자와 검토자는 같은 Ticket·Project 계약을 사용하며 맡은 역할은 Main의 의뢰에서 확인한다. 제품 계약 변경이 필요하면 표현 정리의 범위로 조용히 포함하지 않고 이유와 영향을 돌려준다.
