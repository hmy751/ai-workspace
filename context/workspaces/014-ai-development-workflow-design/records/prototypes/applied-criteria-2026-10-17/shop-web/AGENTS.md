# shop-web 작업 안내

이 프로젝트는 소규모 상점의 React·TypeScript 웹 UI다. 개발·수정·검토를 시작할 때 [Project 안내](context/project/README.md)와 지정된 작업 Workspace의 README를 읽는다. Project 안내는 제품과 현재 계약을, 작업 Workspace는 이번 목표·범위·Ticket·진행 상태를 제공한다.

지정된 작업으로 진입한다. 이 시안에는 [HTTP-07 Workspace](context/workspaces/http-error-contract/README.md)와 [주문 쿠폰 Workspace](context/workspaces/order-coupon-refresh/README.md)가 있다. 두 작업의 진행 상태와 결과는 각각의 README에서 확인한다.

실행 절차는 로컬 [develop skill](.agents/skills/develop/SKILL.md)이 소유한다. 요청에서 맡긴 구현 또는 검토 역할로 진입한다. 구현자와 검토자는 같은 Ticket의 목표와 완료 조건을 사용한다. 검토자는 그 범위 안에서 필요한 품질 수정을 직접 수행하고 수정한 결과를 다시 검증한다.

작업 단서에서 일반 원칙·구체 사례·현재 계약으로 가는 안내는 Project 문서가 소유한다. 이 파일에 별도 안내 표를 복제하지 않는다. 작업 결과·검사 결과·남은 판단은 해당 작업 Workspace에 남긴다.
