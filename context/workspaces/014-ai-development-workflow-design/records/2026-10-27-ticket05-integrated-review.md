# 05 전체 구체안의 자료 대조·독립 개선 리뷰·Main 판단

2026-10-27. 현재 상태: **Main 전체안 작성·자료 대조·독립 개선 리뷰·Main 보완 완료, 사용자 항목별 점검 전**. [전체 구체안](2026-10-27-ticket05-integrated-proposal.md)은 사용자와 점검할 제안이며 채택·설치·실제 효과 확인은 아니다. 아래 조사와 이후 독립 리뷰를 구별한다.

## 전체안을 만들 수 있는 근거와 남은 선택

사용자는 앞선 네 묶음으로 구체화하되, 기존처럼 합의·인터뷰·외부 자료·실제 구조를 먼저 종합하고 독립 개선 리뷰를 거친 뒤 항목별로 논의하자고 했다. 네 묶음의 전체 작성과 리뷰 실행을 시작할 수 있다는 판단이며, 내용의 일괄 채택이 아니다. 직접 요청은 [리뷰 입력](reviews/ticket05-integrated-2026-10-27/README.md)과 인터뷰 후속에 보존한다.

읽기 전용 조사 둘의 결론은 **전체안 작성은 진행 가능하며, 빠진 것은 추가 전면 조사의 선행 조건이 아니라 설계할 연결과 이후 실제 효과 근거**라는 것이다.

### 외부 자료 담당이 확인한 관계

`loop_source_synthesis`는 넓은 조사 기록에서 원문으로 내려가 네 묶음의 근거와 상한을 대조했다. Main은 기존 조사·인터뷰에서 확인한 사실과 함께 초안에 종합했다. 전체 원문 접근점은 구체안의 마지막 표에 있다.

- workflow-from-chats의 발동·판단·품질·중단·근거에서 산출물 형태를 고르는 관계를 활용한다. 경험→기준→스킬의 일률 승격은 만들지 않는다.
- technical-writing의 독자 목적, wayfinder의 결정 가능한 질문과 아직 모호한 불확실성, why의 직접 증거와 해석 구별을 내용·범위 판단에 잇는다.
- reflect·Vercel의 추천/선택/반영 구별, chief-of-staff의 주제 갱신·판단 전 조회를 참고하되 완성된 미결 후보 운영이 있다고 주장하지 않는다.
- retro·Lauren 강연·검증 지식 유지의 실제 수행 수단과 현재 제품 대조를 활용한다. 새 지침뿐 아니라 기존 도구 연결·정보 접근·좋은 예제도 결과가 된다.
- teach·verify-this·hillclimb의 설명과 이해 구별·유효 비교·미확인, show-me-your-work의 실제 결정과 기록 대조, attack-the-premise의 전제 재검토를 효과와 종료 판단에 사용한다.
- 반복 횟수·개인 mode 단일 산출물·사용한 skill만 수신·고정 reviewer 수·무승인 backlog·주간 실행은 우리 합의로 가져오지 않는다.

이 조사에는 새 외부 조회·스킬 실행·도구 효과 검증이 없다. 외부 판본과 조합 제안을 구별한다.

### 기존 구조 담당이 확인한 연결과 빈칸

`loop_existing_connections`는 실제 prototype을 읽고 다음을 반환했다.

> 채택된 개선의 반영·근거 보존·다음 작업의 관련 본문 읽기까지 있다. 미결 후보의 다음 발견·재검토와 효과 관찰을 연결하는 운영은 아직 없다.

주요 근거는 context-update의 반영·읽기 확인·반환, development의 영역별 반영과 Main 책임, Work의 current/records, USAGE의 질문별 원문 선택이다. Main도 context-update·USAGE·내용 정책을 직접 대조했다.

- 기존 중요한 제안·미채택 이유를 Work 기록에 보존하는 계약은 후보층의 새 지속 관리·재조회 계약과 같지 않다.
- Personal README는 현재 개인 기준 중심이다. 협업 경험을 담도록 넓히자는 05 합의를 prototype에 이미 반영한 것으로 읽지 않는다.
- 일반 읽기가 모든 경험/후보를 자동 탐색하거나 다음 실제 효과를 회수하는 계약은 아니다. 구체안4에서 이 연결을 새 제안으로 표시했다.
- 기존 Work가 일상 갱신에 새 제안함·필수 상태값을 만들지 않는다는 문장은 05에서 후보층을 설계할 수 없다는 영구 금지가 아니다. Work의 역할을 축소하지 않는다.

Main은 문서 편집 후속 관찰에서 첫11편의 긍정 평가·기기 세션 조건/순서/예외·효과 상한을 다시 확인했다. 재개 후속 대조의 원문 보존·실제 열람·우선순위 어긋남과 성공 비교를 읽고 Work·development의 현재 재개 책임을 대조했다. 당시 사건을 현재 prototype의 실패로 쓰지 않는다. 후보별 실제 반영 시에는 해당 현재 본문·기존 사례와 다시 대조해야 하므로 ‘이미 없는 내용’이라고 전제하지 않았다.

독립 리뷰는 전체안을 한 번 검토했고, 이후 보완은 Main이 수행·대조했다. 보완판의 두 번째 독립 리뷰나 실제 루프 실행은 하지 않았다. 주요 열린 선택은 남아 있으며, 다음은 사용자와 1번부터 점검하는 일이다. 일반적인 개선 리뷰어를 구현한 것도 아니다.
