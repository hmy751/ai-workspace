# work-discussion 형성 자료 이해·수정 판단과 실행 소비 확인

2026-10-21. **새 실행자는 형성 자료만으로 현재 구성의 이유와 수정 시 보존할 책임을 복원했고, 별도 소비 실행자는 background를 읽지 않고 작업 논의에 답했다.** 각1회 관찰이며 실제 본문 편집이나 일반적인 읽기 안정성을 검증한 결과는 아니다.

## 요청과 방식

사용자는 새 서브가 형성 자료만 보고 현재 구성 이유를 이해하고 수정 판단까지 할 수 있는지, 다른 소비 역할은 불필요하게 `_background`를 읽는지 확인하도록 요청했다. 앞선 지정과 같은 gpt-6.1-sol·medium을 서로 이력이 없는 두 실행에 배치했다. 전체 대화·작성자의 결론·기대 답을 주지 않았다. 형성 자료 실행에는 배경 네 파일만 제공했고, 소비 실행에는 현재 스킬·공통 실행 기준·정책·형성 자료를 모두 접근 가능하게 제공했다. 소비 실행에 background 읽기 금지나 읽기 절약 목표를 주지 않았다.

형성 자료 실행은 “읽을 부담을 줄이도록 본문을 더 간결하게 정리하고 싶다”는 모의 요청에 유지·통합·삭제·유보 판단과 후보 문단을 제안하도록 했다. 소비 실행은 앞선 D2의 금액 표시 통일 요청을 재사용했다. 표시 기준은 미선택이고 나머지 기존 동작은 보존하는 조건이다. 실제 제품 코드 전체는 없고 제한된 관찰을 선제공했다.

모든 입력 본문 읽기는 경로를 기록하는 동일 도구로 수행하도록 했다. 이는 지시 기반 읽기 기록이며 OS 접근 제한이나 전체 도구 이력 감사는 아니다. 실제 평소 도구 선택과 같은 환경이라고 주장하지 않는다. [계획](experiments/work-discussion-background-2026-10-21/protocol.md), [정확한 지시문](experiments/work-discussion-background-2026-10-21/prompts.json), 입력 사본과 해시, 원응답·읽기 기록을 보존했다. 두 실행의 입력 무변경도 확인했다.

## 관찰과 Main 판정

| 확인할 것 | 실제 관찰 | 판단 |
| --- | --- | --- |
| 구성 이유 복원 | 직접 호출·사실 조사·사람 선택·Spec/Ticket·반영 책임을 기존 책임으로 구별했다. 기존 기준의 미수행과 새 관찰 연결 문제에서 최소안을 선택한 이유, 큰 안 비교의 제한, reconsider-work 유지를 설명했다 | 현재 선택의 이유와 확인 한계를 형성 자료만으로 복원했다 |
| 수정 판단 | 중복이면 통합하되 필요한 선택과 새 Work 전체 구체화는 유지하고, 운영 책임 교체는 유보했다. 후보 문단을 제시하면서 현재 SKILL.md가 없으므로 실제 중복·삭제 위치를 확정할 수 없다고 밝혔다 | 조건부 편집 판단과 후보 작성까지 관찰했다. 정확한 diff·실제 수정 수행과 그 후 효과는 미확인이다 |
| 실행 시 읽는 범위 | AGENTS·요청, SKILL.md·공통 설명 기준, 최신 범위·Spec·Ticket·관찰·품질의9개 파일을 읽었다. background와 작성 정책의 본문 읽기는 기록상0회다 | 이 소비 요청에서는 실행에 필요한 자료를 선택했다. background가 아예 없거나 금지돼 생긴 결과는 아니다 |
| 소비 결과의 충분성 | 구분자와 반올림의 미선택을 제시하고 추천을 사용자에게 물었다. 나머지 보존 기준을 다시 선택하지 않았고 실제 코드 미확인·문서 미수정을 밝혔다 | 읽기 생략과 함께 요청에 필요한 구체화도 수행했다. 반올림 제안은 제품 정확성 검증이나 채택된 규칙이 아니다 |

형성 자료 실행은 요청 파일과 배경 네 파일을 읽었다. 본문이 제공되지 않아 문장 단위 편집을 유보한 것은 근거 한계를 지킨 결과다. 다음 실제 수정에서는 현행 본문과 적용 정책을 함께 대조해야 한다. 이번 수정 후보는 시험 응답으로만 보존하며 실제 스킬에 반영하지 않는다.

## 후속 판단

이 두 관찰에서 기존 읽기 안내를 고칠 근거는 드러나지 않았다. 추가 금지문이나 필독 절차는 붙이지 않고 현재 구성을 유지한다. 다른 스킬·복잡한 실제 프로젝트·반복 실행에서의 일반화, 초기 스킬 형성 이력의 완전성은 확인하지 않았다. 모델 출력은 자료 내용을 적절히 복원한 관찰이며 자료에 기록된 역사적 인과를 독립적으로 입증하지 않는다. 정책 적용과04-01의 설계 마감, 실제 설치·장기 효과를 구별한다.
