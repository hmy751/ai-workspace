현재 활성 홈의 상태 전환을 수집하고, 과거 비활성 홈의 문제를 현재 코드·테스트와 대조했습니다. 이미지의 촬영 시점과 여행 활성 상태를 구분해 읽어주세요.

수정 방향 — 같은 제한은 한 번, 개별 오류는 각각

아래는 수집 결과를 바탕으로 한 Main의 제안입니다. 아직 제품에 구현하지 않았으며 변경 후 화면을 다시 확인해야 합니다.

같은 이유로 둘 다 제한

카드 전체 폭에서 설명과 행동 제공

일정·경비가 같은 정책으로 차단될 때만 기존 두 칸을 전체 폭 안내로 대체합니다. 읽을 수 있는 설명과 하나의 재확인 행동을 제공합니다.

문구만 같다고 합치지 않습니다. 확인 중 여부와 가능한 복구 행동도 같아야 합니다. 정책 계산이나 데이터 저장 위치를 새로 만들지 않습니다.

서로 다른 조회 상태

정상 내용과 실패한 영역을 구별

일정은 정상이고 경비만 실패했다면 일정 수는 그대로 보여주고 경비 영역에서만 실패·재시도를 제공합니다. 실패를 0개·0원으로 표시하지 않습니다.

기존 내용의 재조회 실패도 내용을 유지합니다. 같은 제한 안내를 합친다는 이유로 서로 다른 조회 상태까지 합치지 않습니다.

  1. 홈이 두 조회의 제한 상태를 비교하고, 카드가 전체 폭 안내를 배치하도록 최소 변경합니다.
  2. 안내·재확인 개수, 확인 중/불가 전환, 한쪽만 실패한 경우, 활성 Local 표시와 복귀를 회귀 검사합니다.
  3. 비활성 홈을 안전하게 관찰할 조건을 준비한 뒤 설명·버튼 가시성과 줄바꿈을 native 화면에서 확인합니다.

근거와 확인 한계

이번에 확인한 것

  • 현재 활성 홈 4장과 실제 보이는 문구·숫자.
  • 시뮬레이터 수집, 코드 조사, 테스트 범위 대조를 나누고 Main이 결과와 이미지를 확인.
  • 기존 Debug override 해제와 online 홈 복귀.
  • 여행 활성 상태·계정·여행 데이터와 제품 코드를 변경하지 않음.

이번 결과로 보장하지 않는 것

  • 현재 비활성 홈의 신규 재현과 정확한 native 폭 측정.
  • 실제 네트워크 단절·재접속·쓰기·동기화 성공.
  • VoiceOver·큰 글자·키보드를 포함한 전체 접근성.
  • 홈 수정 완료, Ticket 06 전체 검증 또는 사용자 수락.
