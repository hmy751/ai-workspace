# 보고서 첫 전달 전의 실행 원자료

같은 세션의 `.jsonl.zst` 압축본을 발견해 2026-10-22에 도구 원문을 추가 보존했다. 압축 해제본 SHA-256은 기존 corpus 메타와 일치한다. [manifest](manifest.json)는 원 경로·해시·실제 JSONL 줄 번호와 각 추출물의 변환 방법을 소유한다. 기존 공개 발화와 Git archive는 바꾸지 않았다.

각 그룹의 `readings/`는 도구 출력 wrapper만 풀어 쓴 읽기본이다. `images/`는 원 출력의 base64를 복원한 이미지다. `commands/`와 `scripts/`는 실제 생성 명령·heredoc 본문을 그대로 추출했으며 실행하지 않았다. 이들은 현재 디렉터리에 남아 있던 교정 후 HTML과 구별된다. 최초 HTML 파일 전체 바이트를 확보했다고 표시하지 않는다.

**스킬 읽기와 Git 상태:** 원16 호출·19 출력은 이미 초기 `work-artifact-briefing` 본문을 읽었음을 입증한다. 따라서 기존의 ‘선언만 확인’ 한계를 이 범위에서는 해소한다.21 호출·25 출력은 HEAD `0b3b167`, tracked 변경 없음과 `.pnpm-store/` 미추적을 기록한다.748 호출·752 출력도 첫 보고 직전 tracked 변경 없음을 기록한다. 이 두 상태 관측과 기존 archive를 연결할 수 있지만 전체 시간 동안 모든 비추적 파일·DB·앱 상태가 같았다는 뜻은 아니다.

**남은 경계:** 전체 워커 내부 실행·DB 스냅샷은 이 묶음에 없다. 일부 워커 메시지 원 payload는 암호화돼 있어 본문을 복원한 것으로 보지 않는다. 화면 수집 결과와 첫 보고 생성 코드는 확보했지만, 당시 시뮬레이터를 지금 그대로 재실행할 준비와는 구별한다. 시험 조건·평가는 source 밖의 [비교 설계](../../../../records/2026-10-22-ticket04-02-historical-materials-and-comparison-design.md)가 소유한다.
