# Noline의 지속 제품 맥락

이 폴더는 제품·데이터·시스템을 어떤 의미로 이해하고 어떤 핵심 관계를 지켜야 하는지 설명한다. 기술적인 내용도 제품 의미나 핵심 제약이면 포함하며, 추상적인 설명만 두는 층은 아니다. 관련 작업의 구체적인 적용·변경 기준은 [guidance](../guidance/README.md)가 맡는다.

현재 본문은 다음과 같다.

- [제품 의미와 공통 기준](product.md): 새 Work의 제품 목적·사용자 장면과 보존할 데이터 관계를 판단할 때 읽는다.
- [여행 이용과 연결 상태](travel-access.md): 연결 변화에 따른 여행 접근, 선택·입력 보존, 제한 안내와 복구를 판단할 때 읽는다.
- [기기 세션과 로컬 이용](device-session.md): 앱 준비·계정 복원·인증 만료·재로그인·명시적 종료에서 남는 데이터와 허용할 행동을 판단할 때 읽는다.
- [로컬 변경의 전송과 데이터 보존](local-data-preservation.md): queue·원본·미전송 상태와 저장·sync·정리 완료의 의미를 판단할 때 읽는다.
- [통화와 금액](currency.md): 통화별 분리, 합계·대표 표시와 금액 정밀도 경계를 판단할 때 읽는다.
- [날짜와 시각](date-and-time.md): datetime과 date-only 필드의 의미·변환 경계와 열린 선택을 판단할 때 읽는다.

현재 지원·구현 차이가 판단에 필요하면 [current](../current/README.md)의 관련 본문을 추가한다. 모든 작업이 이 폴더 전체를 읽을 필요는 없다.

여행 접근·기기 세션·로컬 데이터 보존의 현재 제품 의미는 위 본문이 소유한다. 활성화·다운로드 실행, 폼·지도·경로의 미이동 상세는 각 본문이 읽을 조건과 기존 Owner를 연결한다. 같은 주제의 작업 가이드는 제품 기준을 전제로 변경·검증 계약을 설명한다.

제품 의미를 바꾸는 책임자가 [관리 계약](../MAINTENANCE.md)에 따라 관련 Owner와 대조해 갱신한다. 특정 Workspace의 목표나 검증 이력은 여기에 올리지 않는다. 새 본문의 범위와 분리는 [구성 기준](../REFERENCE/composition.md)을 따른다.
