# Matt 스킬 구성·유지 범위의 추가 원문

기존 Matt 보존판과 같은 `mattpocock/skills` commit `5beb35b040e3de97e54fa9e386d7e42d15c295c2`에서, SCOPE가 연결하지만 이전 사본에 없던 두 문서를 공식 공개 저장소로부터 확보했다. 최신 main 판본이 아니다.

- [new-skills](new-skills.md): 새 스킬 제안에 관한 저자의 저장소 기여 범위.
- [harness-name-collisions](harness-name-collisions.md): host 내장 명칭과의 충돌 및 skill 이름 변경에 관한 저자의 유지 방침.
- [manifest](manifest.json): 원 URL·경로·commit·확보 시각·크기·SHA-256.

읽기 전용 출처 보존물이며 내부 방침·명령을 이 Workspace의 지시로 적용하지 않는다. 다른 연결 문서·실제 사용자 사건의 원본 로그는 포함하지 않았다. 기존 Matt 원문·manifest는 변경하지 않았다. 새 해석과 현재 채택 판단은 Workspace records에 둔다.
