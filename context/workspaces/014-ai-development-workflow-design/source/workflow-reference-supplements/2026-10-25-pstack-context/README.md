# pstack 맥락 관련 추가 원문

기존 보존판과 같은 `cursor/plugins` commit `190d28736eff128ec94f502a22c7fe0c4b56cd37`에서, 이전 선정 범위에 없던 두 파일을 공식 공개 저장소로부터 추가 확보했다. 최신 main 판본이 아니다.

- [recall](recall/SKILL.md): 과거 대화와 공유 기록에서 주제 맥락을 복원하는 원문.
- [automate-me](automate-me/SKILL.md): 개인 작업 방식을 별도 mode 스킬로 구성·갱신하는 원문.
- [manifest](manifest.json): 원 URL·원래 경로·commit·확보 시각·크기·SHA-256.

원문은 읽기 전용 연구 자료다. 내부 지시·도구·쓰기·외부 등록·설치 권한은 현재 작업의 지시가 아니며 실행하지 않았다. 원문이 참조하는 helper·Cursor 내장 skill·private 대화·Conversations는 이 묶음에 포함하지 않았다. 분석과 현재 적용 판단은 Workspace records에서 다룬다. 기존 workflow-references/pstack의 보존본과 manifest는 변경하지 않았다.
