# 요구 동작과 대표 사례

- `{}`처럼 timeout을 생략하면 `request_timeout_ms=5000`인 policy를 반환한다.
- `{"request_timeout_ms": 1250}`이면 명시한 `1250`을 유지한다.
- `True`와 `False`는 Python에서 정수의 하위 타입이어도 timeout으로 받아들이지 않는다.
- `0`·음수는 양의 정수가 아니므로 거부한다. 소수·문자열·`None`도 거부하며 임의 변환하거나 기본값으로 덮지 않는다.
- `{"timeout_ms": 5000}`처럼 지원하지 않는 키는 오타로 보고 거부한다.
- 반환한 policy의 timeout은 생성 뒤 바꿀 수 없다.

누락과 잘못된 명시값을 구별한다. 기본값은 누락 때만 적용하며, 잘못된 입력을 정상 입력처럼 보정하지 않는다.
