# Common Project context

이 폴더는 여러 Work에 지속되는 제품·사용자·domain 의미와 Project-wide 제약을 소유한다. 제품을 무엇으로 이해하고 어떤 관계를 지켜야 하는지 설명하며, 기술적으로 상세해도 그 의미를 맡는 내용은 포함할 수 있다. 구현 현황이나 한 Workspace의 목표는 두지 않는다.

## 현재 문서

- [`prd.md`](prd.md): Request policy config의 사용자 장면, 목적, 완료 기준과 범위의 normative Owner

새 문서는 반복해서 읽을 독립된 질문과 별도 갱신 책임이 있을 때 추가한다. 모든 주제에 common 문서를 만들거나 구현과 가이드의 전제를 층별 파일로 흩뜨리지 않는다. 구성 기준은 [REFERENCE](../REFERENCE/composition.md)에서 찾는다.
