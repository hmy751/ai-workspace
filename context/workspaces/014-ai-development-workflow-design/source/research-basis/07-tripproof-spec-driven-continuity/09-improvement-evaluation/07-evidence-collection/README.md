# Main과 분리한 사후 평가용 증거 수집

코드와 대화 세션 원본을 활용하면서, 나중에 당시 상황을 검토하는 데 필요한 실행 결과·화면·외부 응답·검토 장면을 보완하는 수집기다. 특정 프로젝트나 평가표를 기본 전제로 삼지 않는다. 수집할 의미와 자료의 관계는 판단하지만 개발 성과와 사용자의 실제 이해·부담 개선은 이후 평가에서 판단한다.

**현재 준비본은 Sol medium을 지정한 독립 실행이다.** 수집 계약, Codex·Claude 어댑터, 원자료 저장과 사건 처리, 예제와 검사는 구현돼 있다. Workspace Maintain용 독립 연결 어댑터와 설치기를 추가했다. 다른 앱·logger의 연결은 각 환경에서 붙여야 한다. Codex의 현재 전역 지침 격리는 macOS에서 검증했으며, Claude의 실제 모델 응답은 아직 인증된 환경에서 확인하지 못했다.

## 현재 읽을 내용

- [수집 대상·시점·기록 계약](collection-contract.md): 왜 이 범위로 수집하는지, 여섯 대상의 확보 시점, 세션과 사건 연결, 당시 상황·자기보고·나중 회고, 수집 가능한 범위와 원자료 관리.
- [실행·이식 안내](v0/README.md): 환경 요구, 실제 설정과 명령, host 연결 책임, 사건·저장 형식, 처리 중 새 사건과 실패·중단, Codex·Claude의 권한·지침 격리, 이식 완료 확인과 제거 방법.
- [검증 결과와 현재 선택 근거](validation.md): Sol medium 선택에 사용한 비교, 현재 구성의 8개 사례와 토큰, 구체적 누락, 검사로 확인한 범위와 아직 확인하지 않은 부분.

이 문서들은 현재 사용할 내용을 소유한다. 과거 보고서를 순서대로 읽어야 현재 결론이 완성되는 구조로 쓰지 않는다. 실제 이식할 파일은 `v0/`에 모여 있고, 역할 본문·schema·실행 코드·예제·검사를 함께 옮길 수 있다.

## 자료와 실행이 이어지는 방식

host는 개발 도구가 실제로 내놓은 사건과 자료를 전달한다. runtime의 `submit`이 당시 원자료를 먼저 보존하고 접수하며, 별도 worker가 사건별로 수집 모델을 호출해 상황 메모와 자료 연결을 만든다. 사용자는 이후 그 기록과 원문을 보고 회고할 수 있고 평가자는 별도로 평가한다.

관찰 대상 Main은 수집기를 호출·대기·승인하거나 결과를 보고받지 않는다. 모델 응답을 기다리는 동안에도 다음 사건은 별도로 접수할 수 있고, 이미 시작한 호출의 입력을 고치지 않는다. 다만 원자료 사본 작성과 CPU·디스크·네트워크 사용량은 발생하므로 실제 동시 작업에서의 간섭은 host에 연결한 뒤 확인해야 한다.

## 지침과 관리의 책임

수집 모델은 [공통 지침](v0/agent/collector-common.md)과 [수집 역할](v0/agent/evidence-collector.md) 두 본문을 읽는다. 앞의 문서는 맥락·의미·근거·시점·출처 해석을, 뒤의 문서는 수집 대상과 실제 입력·출력·권한을 맡는다. [구성 관리 지침](v0/INSTRUCTIONS-MAINTENANCE.md)은 제작·이식·유지보수 담당자가 읽으며 모델 입력에 넣지 않는다. 필요한 글로벌 원칙은 관리 시점에 선별해 두며 매 호출마다 다시 탐색하지 않는다.

이 연구의 현재 내용과 이식 준비본은 이 폴더가, 진행 상태와 논의·구현·시험의 이력은 **Workspace 013**이 소유한다. Main은 사용자가 요청한 제작·관리 작업을 수행하며, 이식 후 관찰 대상 Main은 수집기의 목적·존재·운영 접근점을 알고, 상태 확인이나 중단 요청 때 상세 안내를 읽는다. 사건별 호출·대기·재시도 절차는 Main에게 맡기지 않는다. 적용 범위·자료 접근·운영 한도·사용 여부는 이식 담당자와 사용자가 정한다.

## 갱신과 기록

대상·시점·자료 의미가 바뀌면 수집 계약을, 실행·입출력·이식 조건이 바뀌면 `v0/`의 해당 문서와 구현을, 새 검증이 현재 판단에 영향을 주면 검증 본문을 갱신한다. 논의가 한 번 더 생겼다는 이유로 새로운 번호의 현재 문서를 추가하지 않는다.

지난 선택과 시험의 전체 보고서, 입력·원출력·receipt·당시 코드와 지침은 [013의 수집기 작업 기록](../../../../../workspaces/013-tripproof-pre-application-evaluation/records/2026-09-10-evidence-collection/README.md)에 보존한다. 현재 판단에 필요한 수치·사례·한계는 위 본문에도 남기고, 정확한 과거 표현과 재검증이 필요할 때 기록으로 내려간다. 연구 원문과 상위 평가 설계는 계속 [개선안 평가 준비](../README.md)가 소유한다.
