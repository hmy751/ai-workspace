# 판단 연속성 설계의 새 출발

이 폴더는 AI가 원하는 결과에 도움이 되는 일을 선택하고, 실제 결과로 판단을 갱신하며, 달라진 판단을 다음 작업과 관련된 이전 결과에 반영할 방식을 설계한다.

기존 연구가 쌓이는 동안 목적·선택 이유·검토 조건·변경 이력이 함께 늘어 사용자가 현재 결과를 이해하기 어려워졌다. 2026-09-06 사용자는 기존안 전체를 보존하면서 그 구조에 얽매이지 않고 새로 시작하기로 했다. 필요한 연구 결과와 사용자 논의를 합성한 설계안에 이어, `reconsider-work` 스킬 v0와 사용 안내를 만들었다. 실제 TripProof 적용과 효과 확인은 남아 있다.

## 지금 읽을 문서

실제 결과물부터 보려면 [v0 사용 안내](v0/README.md)를 읽는다. 2026-09-07 채택 뒤 원래 문제 분석과 대조해, 코드가 다음 변경을 받는 기준과 기존 제품 제약·내부 선택의 구분을 보완한 본문으로 연결한다. 이전 판본의 시험과 현재 문서의 확인 범위는 구분한다.

먼저 [`01-starting-point.md`](01-starting-point.md)에서 원래 문제와 현재 연구 결과가 어떻게 연결되는지 읽는다. 그 결과의 내용은 아래 두 본문에 직접 구성했다.

- [`02-v1-v2-findings.md`](02-v1-v2-findings.md): 원래 실패의 관계, V1의 진전과 부족함, V2가 선택·완료·이전 결과에 넣은 차이를 사례와 함께 설명한다.
- [`03-matt-findings.md`](03-matt-findings.md): 판단을 만드는 일, 실행에 전달하는 일, 오래 남길 지식의 역할과 수명을 실제 자료에서 살펴보고, 그 구분으로 해결되는 부분과 남는 부분을 설명한다.

현재 설계는 [`04-solution-direction.md`](04-solution-direction.md)에서 읽는다. 먼저 한 작업에서 무엇을 다시 보고 다음 행동이 어떻게 달라지는지 따라간다. 이어 필요한 정보를 고르는 방법, 판단을 작업에 남기는 방법, 코드 상황의 대비와 구성 후보·열린 질문을 설명한다. 자료별 도출 이유는 본문 뒤에 연결했다. 실제 실행 결과를 보고한 문서는 아니다.

현재 설계를 이어가는 데 필요한 결론·이유·한계는 이 문서들에서 이해할 수 있다. 원자료 링크는 해석을 다시 확인하는 경로다.

이전 분석을 순서대로 다시 읽거나 기존 실행 계약의 항목을 채우는 방식으로 시작하지 않는다. 원래 문제의 상세 근거가 필요하면 상위 폴더의 [문제 분석](../01-problem-analysis.md)과 [source 안내](../../../source/07-tripproof-spec-driven-continuity/source.md)로 내려간다. 출발 문서에 연결된 원자료의 모든 질문이 이번 설계의 필수 요구사항인 것은 아니다.

## 자료의 책임

이 README는 현재 목표와 문서의 역할·읽기 경로를 소유한다. 01은 문제·연구 결과·현재 설계를 연결하고, 02·03은 선별해 재구성한 연구 결과의 본문을, 04는 현재 해결 방향과 열린 설계 질문을 소유한다. 새 v0는 현재 실행 지침과 사용 방법을 소유한다. 실제 시험 당시의 입력·응답·검토는 011 records에 남긴다. [Archive](archive/README.md)는 이전 분석·설계와 옛 v0를 당시 상태로 보존한다. Archive 본문은 과거 판단의 이유나 특정 실패를 대조할 필요가 있을 때 선택해 읽는다. 현재 설계와의 자동 동기화나 과거 조건의 자동 상속은 없다.

[011 Workspace](../../../../workspaces/011-tripproof-judgment-continuity-reassessment/README.md)는 이 작업의 목표·진행·선택 자료·산출물 지도·기록을 관리한다. 연구 본문은 계속 이 analysis 폴더가 소유한다. Main이 사용자 선택과 원자료에 따라 현재 설명을 관리하며, 사용자의 이해와 중요한 범위·최종 수용은 사용자가 판단한다.

자료 보존과 새 출발점 구성은 완료된 설계나 실제 적용 효과를 뜻하지 않는다. 공동 적용·설치 파일 준비는 별도로 남겨둔 010 Workspace의 후속 목표다.
