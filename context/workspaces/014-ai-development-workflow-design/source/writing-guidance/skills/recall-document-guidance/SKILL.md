# 문서 작성 기준 상기

작업이 이어지면서 기존 작성·관리 기준이 판단에서 빠지는 문제를 보완하기 위한 스킬이다. 기준을 새로 정의하지 않고 문서를 작성하는 시점에 다시 상기시킨다.

문서를 작성·갱신할 때, 대상 문서의 역할과 작업 영역에 적용되는 전역·로컬의 작성 및 관리 기준을 상기하고 적용한다.

- 전역 기준은 `~/.claude/references/`의 관련 `ai-system` references 등에서 찾는다. 지침의 요구와 적용 조건을 작성할 때는 `ai-system_instruction-clarity.md: 적용`, 사람이 필요한 답과 판단 지점을 찾게 구성할 때는 `ai-system_human-readable-structure.md: 적용`.
- 로컬 기준은 해당 프로젝트·작업 영역의 지침에서 찾는다. 예를 들어 문서 구성 기준, MAINTENANCE, Workspace 문서 작성 기준 등이 해당한다.

현재 맥락에 관련 내용이 있으면 활용한다. 필요한 내용이 없거나 변경 여부·적용 범위를 확인해야 하면 해당 정본을 읽는다.

관련 기준을 상기하고, 그 취지를 문서의 목적·독자·보존 요구에 맞게 적용한다.

스킬의 역할이나 적용 범위를 바꿀 때는 [도입 배경과 참고 근거](../../CLAUDE.md.history#recall-document-guidance-2026-09-30)를 확인한다.
