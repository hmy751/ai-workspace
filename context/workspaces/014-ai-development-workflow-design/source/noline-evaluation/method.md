# 수집 방법과 판단 한계

이 묶음은 Noline에 Context Harness를 이식하고 Ticket 06까지 개발한 과정을 평가할 원자료와 장면 후보다. 특정 완료 보고서를 정답으로 놓고 검증한 결과도, 하네스 효과를 판정한 성적표도 아니다. 사용자가 기록을 먼저 읽어 장면을 찾도록 요청했으며, 침묵·짧은 동의·질문 횟수로 편안함이나 문제를 추정하지 않기로 했다.

## 범위

대화 시각은 한국 시각 2026-09-04 00:00부터 2026-10-07 00:00 직전까지다. 최초 이식 커밋은 `b4ed41f6e4bbae26fd45827b3b9063097a2c1ea4`, Ticket 06 종료 기록은 `4fb309d2ba50afaca44019879d7161964b9b2328`이다. 직전 기준 `74926b8e33f87c04ec11a25991733f1b8bc3cbdc`까지 포함해 first-parent 85개 커밋을 색인했다. 기준 커밋은 5월이므로 85개 모두가 관찰 기간 중 커밋이라는 뜻은 아니다.

Noline cwd/workspace root를 가진 Codex 활성·보관 세션을 session_meta로 발견했다. 최초 이식은 Context Harness 폴더에서 진행되어, 별도 근거를 따라 찾은 세션을 명시적으로 추가했다. Noline 밖의 모든 개발 대화를 전수 탐색한 것은 아니다. 로컬 밖 대화가 거의 없었다는 사용자 설명을 범위 설정에 사용했다. 현재 확인한 Claude 프로젝트 폴더 최상위에는 JSONL 원문이 없었으며 다른 모든 Claude 보관 위치에 원문이 없다는 뜻은 아니다.

## 물리적 추출과 의미 검토

1. Python으로 커밋·대화·collector의 파일 위치, 시각, 해시, 연결 관계를 만들었다. 원문 전체를 큰 모델에 보내지 않았다.
2. 공개 발화 텍스트를 정확히 보존하고, 도구 본문과 내부 추론은 읽기 본문에서 제외했다. 도구 실행의 line/call ID/크기/해시는 세션별 `tools.jsonl`로 남겼다. 의미가 필요한 장면에서는 해당 원본으로 돌아갈 수 있다.
3. 독립 기술 QA로 collector 원문 17개 포함 여부, wrapper 제외, 역할 구분과 세션 간 재생 중복을 대조했다. `<skill>` 안내문과 실제 사람 요청을 분리했다. 브라우저 상태와 실제 요청이 한 메시지에 함께 있는 경우는 요청을 보존했다.
4. 직접 대화 46개의 4,156개 메시지를 120개 읽기 구간, 9개 batch로 나눴다. 모든 메시지가 한 구간에 정확히 한 번 들어간다. 전체 대화에 접근할 수 있어 경계를 넘어 앞뒤를 확인할 수 있다.
5. Sol high가 원문 구간을 읽고 장면·평범한 구간·미확정을 반환한다. 키워드로 문제 후보만 선별하지 않는다. 별도 Astra high 검토는 원문 표본에서 먼저 독립 판단한 뒤 추출 결과를 대조한다. 실제 검토 범위와 결과는 `reviews/`에 남긴다.
6. 인용이 실제 메시지의 부분문자열인지, 메시지 위치가 존재하는지, 읽은 구간 목록이 입력과 맞는지 기계 검증한다. 이는 원문 연결 검증이며 의미 판단의 정답을 증명하지 않는다.

`inventory/corpus-stats.json`의 1,827,213은 추출한 본문의 **문자 수**다. 552,770,070은 선택한 원본 파일 전체의 **바이트 수**이며 관찰 기간 밖 이벤트와 도구 자료도 포함할 수 있다. 둘의 비율을 토큰 절감률로 해석하지 않는다. 모델별 실청구 토큰·비용을 계측한 비교 실험은 수행하지 않았다. 토큰을 줄인 지점은 도구 본문 제외, 자동 안내문 제외, 본문 읽기 분담, 중복 본문 대신 장면 인용 전달, 높은 비용의 독립 검토를 표본과 쟁점으로 제한한 것이다.

## 관찰과 해석

장면의 `observed`는 확인한 발화·행동 순서다. `interpretation`은 평가할 가설이며 `alternatives`와 `unknowns`를 함께 읽는다. `ordinary_spans`는 뚜렷한 후보로 고르지 않은 구간의 접근점이다. 이것이 불만 없음·만족·이해 완료를 뜻하지 않는다. 하나의 장면이 여러 관점에 관련돼도 독립 성과 여러 건으로 합산하지 않는다.

사람이 자신의 말로 구조나 조건을 재진술하고 선택한 경우, 그 발화는 관찰할 수 있다. 그것만으로 장기 기억·이해의 정확성·감정·전체 부담 감소까지 확정하지 않는다. assistant의 테스트 통과·완료·기록 반영 보고는 실제 실행 출력이나 diff를 추가 대조하기 전까지 **당시 보고**다.

07·09 연구에서 이어받은 질문은 필요한 결과의 충족, 코드 품질과 실제 후속 변경, 사람의 이해·판단·부담이다. 세션 사이 연속성은 이 관점들을 후속 작업에서 살펴보는 장면이며 별도 종합 점수로 만들지 않는다. 현재 충분성, 이전보다 나아짐, 특정 하네스 요소의 기여는 각각 다른 근거를 요구한다.

## 관찰의 빈틈

- 기존 collector의 697개 이벤트 중 222개는 파생 기록 생성에 실패했다. 대응 원문이 없었다는 뜻이 아니다. 기존 기록 475개도 기계적 정답이나 사용자 수용 판정으로 쓰지 않는다.
- 명시적 subagent/guardian 334개는 발견 목록에 남기되 사람 대화 46개와 별도로 둔다. Maintainer 17개, 사람이 없는 자동 생성 대화 1개도 별도 분류했다. 위임 결과의 독립 품질을 전수 검토하지 않았다.
- 공개 메시지의 비텍스트 첨부 4개는 위치만 색인했다. 도구가 반환한 스크린샷이나 실행 출력도 이 텍스트 장면 읽기에서 전수 관찰하지 않았다.
- 로컬 메시지 안에 삽입된 ChatGPT 대화 참조와 캐시된 발췌는 그대로 보존했다. 예를 들어 마지막 세션의 TimeField 논의에 외부 설명이 들어 있다. 외부 대화 전체를 새로 수집하거나 확인했다는 뜻은 아니다.
- 이식 전에도 `.claude` 하네스가 있었고, 이식 뒤에도 9월 10–14일 등을 거치며 지침이 바뀌었다. Ticket 06의 요구도 커졌다. 단순 전후 차이를 하나의 고정된 도입 효과로 귀속할 수 없다.
- 경과 시간과 사람이 직접 일한 시간은 다르다. 세션 간 공백, 짧은 답, 로그 부재로 부담이나 편안함을 추정하지 않는다.

## 보존과 재접근

`corpus/`는 공개 발화와 도구 접근점, `documents/`는 선택한 문서 판본을 보존한다. 전체 원본 로그를 별도 복제하지 않았지만, 의미 판단에 쓴 공개 발화는 원본 line과 함께 이 묶음에 보존했다. `episodes/`는 이 원문 위의 파생 해석이다.

`inventory/documents.json`은 커밋·문서 경로·blob snapshot을 연결한다. 같은 문서 내용은 한 번만 저장했다. 연구 문서 32개는 현재 파일의 SHA-256과 snapshot을 함께 남겼다. 제품 코드 전체를 복제하지 않았으며 코드 접근은 커밋과 경로로 이어간다.

수집 스크립트는 원본을 읽고 이 artifact 폴더에만 결과를 쓴다. source collector의 설치·실행·재시도·상태 변경, 제품 코드 수정, git commit은 수행하지 않는다. 재실행하면 파생 파일을 덮어쓰므로 현재 검토 결과와 다른 판본을 만들려면 새 artifact 폴더에서 진행한다.
