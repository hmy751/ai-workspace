# 현재 논의의 진입점

**현재 중심은03이며 Personal context의 위치·책임 방향을 정한 뒤 실제 본문 구성을 이어갈 단계다.** 개인 개발 기준의 중앙 정본을 ai-workspace의 `context/personal/development/`에 두고, Project guidance가 채택·구체 적용·예외와 해당 Project의 개발 계약을 소유하는 방향이다. 현행 context 계약을 확장하는 설계이며 실제 디렉터리 생성·기준 이동·통합·설치는 없다. 구조 정정과 사용자 선택의 근거는 [81](../records/2026-10-19-81-personal-context-direction-and-next-step.md)에 있다.

다음 Main 추천은 **이름과 실제 책임·완료 범위** 한 주제로 개인 기준·Project 본문·읽기 안내를 한 세트로 제시하는 것이다. 이 주제는 아직 사용자 선택·본문 작성 전이다. [state](state.md)에서 남은 판단과 다음 행동, [03](tickets/03-project-context.md)·[04-03](tickets/04-skill-improvements/04-03-context-skills.md)에서 맡은 결과와 읽기·갱신의 연결을 확인한다.

## 문서별 책임

- [memory.md](memory.md): 배경과 평가에서 얻은 경험, Spec·Ticket을 쓰게 된 흐름.
- [spec.md](spec.md): 전체 목표·공통 기준·잠정안·사용자 선택·미정.3절은 전체 체계와 현재 초점을 연결한다.
- [tickets/index.md](tickets/index.md): 상위01~07과 하위 Ticket의 관계. 각 Ticket은 상세 결과·완료 조건·진행을 소유한다.
- [state.md](state.md): 현재 작업 중심, 다음 추천, 미실행 범위와 재진입 경로. 과거의 날짜별 진행은 records에서 찾는다.
- [design-map.md](design-map.md): 전체 분해에서 놓친 관점을 살피는 열린 논의 지도. 확정 아키텍처가 아니다.
