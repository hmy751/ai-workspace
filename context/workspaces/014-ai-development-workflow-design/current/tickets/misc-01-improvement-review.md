# 기타-01 — AI와 일하는 과정에서 쓰는 개선 리뷰를 구체화한다

상태: **후속 보관 · 사용자 요청으로 지금은 논의·설계·구현하지 않음**.

## 남겨둔 의도

사용자는 단순히 현재 안이 적절한지 판정하는 데서 그치지 않고, 어떻게 하면 더 나아질지 찾는 개선 리뷰를 원했다. 이런 판단 보조 방식을 향후 스킬 등의 형태로 만들 생각이 있었으며, 경험 반영 루프에 한정하지 않고 AI와 일하는 여러 과정에서 사용할 대상으로 보았다.

현재는 의도와 열린 질문을 보존한다. 새 스킬·agent를 만들거나 기존 역할을 수정하지 않는다. 05의 선행 완료 조건이나 루프의 필수 단계로 정하지 않았다.

## 사용자 원문과 경과

최초 요청 중:

> 개선 리뷰어로 끌어올릴 단순 적절하다 판단 말고 여기서 더 잘하게 하려면 어떻게 해야하나 그런리뷰도

범위에 관한 후속 발화:

> 개선리뷰는 안그래도 나중에 뭔가 스킬이나 그렇게 만들면 좋겠다는 생각은 했어 이건 루프 한정이라기보다 어떤 내가 Ai와 일하는 과정에서 하는 판단이나 그런 스킬? 뭐 아무튼 그런 종류라서 음 말 나온김에 이것도 정할까? 근데 이건 루프 한정은 아니긴해서

이번 분리·보류 요청:

> 그래 그럼 이건 나중에 다시 정해보고 구체화할게 그냥 하나 티켓 별도로 만들어서 기타 사항처럼 하나 만들고 이거 기록 해놔줘 지금 하진 말자

[05 인터뷰의 형성 맥락](../../records/2026-10-27-ticket05-interview.md#논의-확장--루프-밖에서도-쓰는-개선-리뷰)과 [앞서 한 번 수행한 개선 리뷰](../../records/2026-10-27-ticket05-collaboration-learning-review.md)를 참고한다. 해당 리뷰는 당시 제안에 대한 수행 기록이며 범용 역할의 설계·효과 검증은 아니다.

## 나중에 다시 판단할 것

- 무엇을 대상으로 어떤 상황에서 부르면 유용한가: 판단·접근법·산출물 등은 Main이 제시한 후보이며 고정 목록이 아니다.
- 현재 안을 발전시키는 데 더해 문제를 보는 관점과 접근법 자체의 변경 제안까지 맡길지. 직전 질문에 대한 명시적 선택 없이 구체화를 보류했다.
- 기대 효과·비용·불확실성과 유지할 부분을 어떻게 제시하면 사용자가 선택하기 좋은가.
- 기존 advisor-context, ai-self-check, 개발 과정의 개선 검토와 어떤 역할을 공유하거나 구별할지.
- 기존 스킬 보완, 별도 스킬, 재사용하는 역할 중 어떤 형태가 맞을지. 스킬 신설은 확정하지 않았다.
- 05 루프에서 활용한다면 어떤 조건으로 연결할지. 기본 실행 여부·빈도·담당·반영 권한은 미정이다.

Main이 제시했던 역할 초안은 ‘목적과 근거에 비추어 현재 판단·접근법·결과물을 보고 가치 있는 개선과 대안을 제안한다’였다. 이는 후속 논의의 재료이며 사용자 확정 요구로 승격하지 않는다.
