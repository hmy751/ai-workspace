# 01-01 — 개발 진행과 사람의 판단을 연결한다

상위 과제: [01 개발 작업 방식](README.md)

상태: **분해 정리 완료 · 설계 작업 미착수**. 전체 기준은 [Spec](../../spec.md)에 있다.

## 맡은 결과와 범위

목표·Spec·Ticket에서 조사·설계·구현·검토·수정·첫 보고까지 이어지는 **대표 작업의 진행안과 판단 책임의 선택 근거**를 만든다. AI가 필요한 일을 찾아 수행하는 부분과 사람의 제품 선택·이해·재판단이 필요한 지점을 구체화한다. Main·worker·reviewer의 수나 고정 호출 순서는 아직 정하지 않는다.

이 Ticket은 전체 진행과 책임의 연결을 맡는다. 코드·설계 품질의 실제 기준과 검토·수정 방법은 [01-02](01-02-code-design-quality.md), 동작 검증과 도구는 [01-03](01-03-behavior-verification.md)가 구체화한다. 두 결과를 받아 진행안을 보완하되, 먼저 연결 초안을 만들어 기록·Project 논의를 시작할 수 있다.

## 처음 만들 결과와 근거

Noline의 여행 조회·네트워크 복구 작업 일부를 첫 사례 후보로 삼아, 원하는 결과·유지할 동작·미정 선택, 필요한 조사, 사람이 판단할 지점, 결과 확인·첫 보고·기록의 관계를 펼친다. 이후 작은 변경과 구조 개선에서 필요한 작업이 어떻게 달라지는지 비교한다. 사례 후보를 채택하거나 분석한 결과는 아직 없다.

- [기존 실행 기준](../../../source/ai-workspace-baseline/reference-project/context/work/workspaces/spec-and-tickets/EXECUTION-CRITERIA.md): 필요한 일의 발견, 목표·실행·완료의 관계.
- [철회와 후속 구현 비교](../../../source/reading/noline-evaluation/reviews/withdrawal-followup-comparison.md): 가독성 작업에서 동작 개선을 의도적으로 수용한 사실과 당시 철회 동기의 불확실성.
- [평가·인터뷰](../../../records/2026-10-12-01-background-and-evaluation.md): 필요한 사람의 선택·학습과 반복 교정의 구별.
- [기반·강연 읽기](../../../records/2026-10-12-02-framework-and-lecture-reading.md): 자동 검사·AI 검토·사람 판단의 관계와 비용.

## 다른 Ticket과 주고받을 것

[02](../02-work-records.md)에는 실제로 생기는 기록과 다시 사용할 장면을, [03](../03-project-context.md)에는 작업 주체가 소비할 맥락을 제시한다. [04-01](../04-skill-improvements/04-01-work-decision-skills.md)은 작업 정의·재판단을 실제 스킬로 연결하고, [04-02](../04-skill-improvements/04-02-artifact-explanation.md)은 첫 보고와 별도 브리핑·설명 복구를 구별해 보완한다.

01-01은 검토 지적의 판단·수정·재확인이 작업 흐름 어디에 놓이는지 맡고, 01-02·01-03는 그 판단에 필요한 품질 기준과 증거를 구체화한다. 미정인 부분을 확정된 역할 배치로 채우지 않는다.

## 완료 조건과 확인 방법

- 대표 작업에서 목표를 결과로 나누고 필요한 조사·개발·검토를 찾는 방법이 구체적이다. 초안 파일 목록을 처리한 것으로 목표 달성을 대신하지 않는다.
- AI가 더 확인할 때, 판단 가능한 결과를 제시할 때, 사람의 선택이나 추가 관찰이 필요한 때를 사례로 비교한다. 중요한 사람 참여를 모두 줄이는 목표로 만들지 않는다.
- 검토 지적의 판단·수정·재확인·종료, 첫 보고와 기록의 책임이 연결된다. 01-02·01-03의 선택과 충돌하거나 빠진 부분을 드러낸다.
- 작은 변경과 큰 구조 개선에서 적용할 방법과 생략할 방법, 역할·자료·도구 비용, 이후 관찰할 품질·사용자 부담을 설명한다.
- 결과는 검토 가능한 진행안이다. 초기 연결 초안과 관련 결과를 반영한 설계 완료를 구별하며, 설계의 채택·구현·효과 확인을 완료로 앞당기지 않는다.

현재는 결과 분할과 근거 연결만 정리했다. 진행안·역할 배치·개발 방법을 선택하거나 실행하지 않았다.
