# Project application current

마지막 갱신: `2026-08-16`

이 폴더는 실제 Project 적용 작업에서 다음 세션이 바로 판단하는 데 필요한 최신 상태를 소유한다.

## 재진입 순서

1. [`memory.md`](./memory.md)에서 적용 목표·대상 구분·지속 기준을 확인한다.
2. [`state.md`](./state.md)에서 skill 재보강·재시험 없음·v3 target 미보정 상태를 확인한다.
3. [`../output/index.md`](../output/index.md)에서 현재 절차와 v3 결과의 미완료 경계를 확인한다.
4. 최신 사용자 정정과 Owner closure 규칙은 [정정 기록](../records/2026-08-16-03-project-context-owner-closure-correction.md)에서 확인한다.
5. 이전 계약의 이유가 필요할 때만 [`../records/`](../records/)의 과거 기록을 읽는다.
6. 원자료를 재확인해야 할 때만 [`../../../source/`](../../../source/)를 연다.

다른 Workspace의 current나 records는 사용자 지시 없이 이 Workspace의 현재 상태로 가져오지 않는다.
