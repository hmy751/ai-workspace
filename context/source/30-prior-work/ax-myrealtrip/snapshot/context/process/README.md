# process — 시간순 과정 기록

작업하면서 생기는 생각, 판단, 결정, 과정을 시간순으로 적는 곳이다. 과거 기록은 사후에 고쳐 쓰지 않는다 — 판단이 바뀌면 새 항목으로 남긴다.

## 기록 원칙

- 그 판단이 생긴 세션에서 그때그때 적는다. 몰아 쓰지 않는다.
- 매 판단에 태그를 단다: **결정 / 가정 / 기각 / 검증 필요**.
- 결정에는 이유만이 아니라 대안, 기각한 제안과 그 이유, 아직 검증 안 된 것을 함께 남긴다.
- 파일을 종류별로 미리 나누지 않는다. 시간순으로 만들고(번호나 날짜), 필요할 때 태그와 검색으로 찾는다.
- 막힌 지점과 해결 과정도 판단처럼 그때그때 남긴다.
- 단계 게이트의 보고 파일도 여기 시간순으로 쌓인다 — 고정 슬롯 규칙은 context/current.md의 실행 스캐폴딩.
- 문항 답변(1·2·4·5=800자, 3=1000자)의 재료가 여기서 나온다 — 특히 "기각한 AI 제안과 그 이유"와 "막혔던 지점·해결 과정"(문항4), "무엇을 의심했고 무엇이 아직 부족한지"(문항5).
- 조사 산출물(주장→근거 연결, 조사 정리)은 여기가 아니라 context/research/에 둔다.
- 현재 문제 후보·비교·선택 결과는 context/problem/에 두고, 여기에는 왜 합치고·기각하고·선택했는지의 이력을 남긴다.
