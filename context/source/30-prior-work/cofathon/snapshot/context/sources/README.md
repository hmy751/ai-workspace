## 사용자 작업 증거의 원위치

아래 자료는 위 마이리얼트립 입력 다섯 파일을 제외하면 이 폴더에 통째로 복사하지 않고 원래 프로젝트에서 확인한다.

- `~/Desktop/10_work/tripproof` — AI 제품 구현·검증·공개 상태
- `~/Desktop/10_work/AX인재전쟁-해커톤` — 제한 시간 작업의 조사·구현·검증·제출 기록
- `~/Desktop/10_work/noline` — 실제 App Store 출시 제품
- `~/Desktop/10_work/dev-hub`, `~/Desktop/10_work/ai-note` — 자기 서술·회고·관찰. 단독 사실 근거가 아니라 확인 후보로 사용

다른 AI가 만든 분석은 조사 질문을 찾는 입력으로만 사용하고, 공식 사실이나 사용자 역량의 독립 증거로 승격하지 않는다.
